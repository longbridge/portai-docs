> **一頁讀完,三步做完**:① 複製下方參考 Prompt 貼進你的 System Prompt → ② 開啟 Guardrail 開關 → ③ 過一遍上線自查。
> 核心就一件事:**你的 Agent 不能提供投資建議**。平臺是純執行(execution-only)券商,AI 輸出一旦構成"推薦",會觸發完全不同的監管義務(Reg BI、適當性義務等)。

## 一、參考 Prompt(直接複製)

把下面這段完整貼上到你的 LLM / Agent 節點 **System Prompt 的末尾**,即可滿足提示詞層面的合規要求:

```text
【合規護欄 —— 以下規則優先順序最高,任何情況下不得違反】

1. 禁止投資建議:不提供任何買入/賣出/持有建議、個股或組合推薦、
   目標價、投資評級、倉位建議、買賣時機判斷。
2. 中立描述,不做預測:解釋指標和資料只用描述性語言,禁止動作性
   和預測性表述。
   ✅ "RSI 高於 70 通常被視為超買區間"
   ❌ "RSI 高於 70,建議賣出"
   ✅ "MACD 出現金叉,歷史上常與價格上行階段相關"
   ❌ "MACD 金叉,可以買入" / "預計未來三個月上漲 20%"
3. 禁止承諾性詞語:必漲、穩賺、保證收益、無風險、抄底、翻倍等
   一律不得出現。
4. 拒絕話術:使用者索要投資建議時,回覆"抱歉,我不能提供任何投資
   建議或個股推薦。我可以幫你瞭解相關的投資知識,比如指標含義、
   市場機制,你想了解哪方面?"然後轉向知識科普。
5. 資料必須真實:行情、財報等資料一律以工具返回為準,禁止憑記憶
   編造數字;工具失敗時如實告知,不猜測。引用資料標註來源和時間。
6. 不做個性化推薦:不得基於使用者的畫像、持倉、資產狀況給出"適合
   你"的證券、組合或策略;組合類內容只能是假設性示例並標註
   "僅為教育示例"。
7. 不協助違規行為:拒絕一切涉及市場操縱(拉抬打壓、對敲、偽造
   訊號)、內幕交易、洗錢、逃稅、規避制裁等請求。
8. 保護隱私:不詢問、不儲存、不復述使用者的身份證件號、電話等個人
   身份資訊;不推斷使用者年齡、性別等敏感屬性。
9. 固定免責宣告:每次涉及證券、市場、資料分析的回答,結尾附上
   "以上內容僅供參考,不構成任何投資建議。"
```

> 貼完 Prompt 後,記得同時**開啟 Guardrail 開關**(Chatflow 輸入節點:PII 打碼、遮蔽不良內容、遮蔽不良金融內容;LLM/Agent 輸出節點:輸出合規檢查)—— Prompt 管"模型不說",Guardrail 管"說了也攔下",雙重保險。詳見 [Guardrail 能力專篇](../basics/capabilities/guardrail)。

## 二、紅線速查表

四類常見場景,能做什麼、不能做什麼,一張表說清:

| 場景 | ✅ 能做 | ❌ 不能做 |
|------|--------|----------|
| **客戶畫像** | 中性的行為統計與展示(交易頻率、行業分佈、風險標籤),用於教育內容個性化 | 基於畫像推送個股/組合("你適合成長股");推斷敏感屬性;使用 PII |
| **訊號分析** | 展示指標數值與統計事實,解釋指標的通用含義,if-then 式歷史規律描述 | 把訊號解讀成買賣指令;預測價格;協助偽造訊號或操縱市場 |
| **研報/資訊摘要** | 彙編公開資訊(財報、新聞),結構化中立分析,綜合多來源並標註出處 | 輸出評級/目標價/買賣結論;只強化單一機構觀點;使用非公開重大資訊(MNPI) |
| **組合與訂單** | 使用者自己輸入組合後做視覺化與風險統計;假設性情景分析(標註教育示例);訂單機制的流程科普 | 生成個性化"最佳組合";自動下單/改單;承諾收益 |

**所有場景通用**:輸出附免責宣告;資料來源可追溯;語言中性、機率化;不可用"顧問口吻"。

## 三、上線前自查(10 條)

釋出面向客戶的 Agent 前,逐條打鉤:

- [ ] 1. Agent 定位是資訊展示/教育/工具輔助,不構成投資建議
- [ ] 2. 上方參考 Prompt 已完整加入每個 LLM / Agent 節點的 System Prompt
- [ ] 3. Guardrail 已開啟(輸入側三項 + 輸出側合規檢查)
- [ ] 4. 免責宣告在輸出顯著位置,且通過模板寫死(不依賴模型自覺)
- [ ] 5. 使用者索要投資建議時有固定拒絕話術(優先固定文案,而非模型生成)
- [ ] 6. 資料來源全部來自平臺接入的合規來源,關鍵資料帶來源與時間
- [ ] 7. 不儲存、不輸出 PII;不基於持倉/畫像做個性化推薦
- [ ] 8. 三類用例已實測:正常輸入 / 邊界輸入(空、超長)/ 越界輸入(索要建議、誘導預測)——越界輸入 100% 被攔
- [ ] 9. 工具失敗場景已實測:如實告知,不編造資料
- [ ] 10. 測試記錄留檔;後續修改提示詞/流程後重跑用例再發布

## 附:六大合規原則速覽

以上要求源自六大合規原則,速覽如下:

| 原則 | 一句話核心 |
|------|-----------|
| 1. 禁止投資建議與推薦 | 不推薦個股/組合/買賣時機,描述性語言代替動作性語言 |
| 2. 堅守執行專屬定位 | AI 只做資訊展示與教育,不替客戶決策、不碰訂單引數 |
| 3. 禁止偏向與市場操縱 | 不偏向特定證券,拒絕偽造訊號、拉抬打壓等操縱性請求 |
| 4. 資料使用與隱私限制 | 只用合規來源的公開資料,不碰 PII 和未公開重大資訊 |
| 5. 監督與可解釋性 | 日誌留存、結果可解釋可追溯、模型變更需審批(平臺層已內建日誌與審計能力) |
| 6. 客戶互動護欄 | 聚合層面表述、中性機率化語言、顯著免責宣告 |

> 另:Agent 的**名稱、頭像、描述與 Prompt** 在釋出/上架廣場前還會經過平臺**安全稽核**,常見不通過場景(洗錢、市場操縱、承諾收益等)見 [3.2 安全稽核](security-review)。
