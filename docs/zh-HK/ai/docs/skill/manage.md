# 管理 Skill

本文說明如何在 Skill 詳情頁編輯信息、管理工具與文件，以及如何下載和刪除 Skill。

## 編輯名稱和描述

在 Skill 詳情頁，點擊 Skill 名稱旁的編輯圖標，彈出「編輯 Skill」面板。可在此修改名稱和描述，點擊「保存」生效。

修改時須注意：

- 名稱僅限小寫字母、數字和連字符，最大 64 字符
- 描述最多 1024 字符，不支持換行
- 名稱在工作空間內需唯一，修改為已存在的名稱將失敗

## 編輯 SKILL.md

SKILL.md 是 Skill 的核心定義文件，展示在詳情頁下方。點擊 SKILL.md 區塊右側的「編輯」按鈕，可直接在線修改文件內容。

建議在修改 SKILL.md 時同步更新描述字段，保持兩者的一致性，便於模型準確理解 Skill 的用途。

## 管理工具

工具讓 Skill 在執行時具備調用外部能力的能力。在詳情頁「工具」區塊點擊「+」添加工具，支持兩類來源：

| 來源           | 說明                                                        |
| -------------- | ----------------------------------------------------------- |
| Infra 內置工具 | 系統預置，無需額外配置，開啟即用                            |
| OpenAPI 工具   | 通過 OpenAPI 規範接入自訂接口，適合調用內部系統或第三方服務 |

已添加的工具可通過開關啟用或禁用，也可刪除。

## 管理文件

文件為 Skill 的執行提供背景資料和配置支持，例如分析規則、參考示例、行業數據等。在詳情頁「文件瀏覽器」區塊點擊「+」管理文件，支持以下操作：

| 操作         | 說明                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 添加文件     | 從本地選取文件上傳                                                                                     |
| 添加文件夾   | 創建文件夾，用於對文件進行分類管理                                                                     |
| 編輯文件內容 | 點擊文件旁的「編輯」按鈕，可在線修改文件內容，完成後點擊「保存文件」生效。**注意：不支持修改文件名。** |
| 刪除文件     | 永久刪除該文件，不可撤銷、不可恢復                                                                     |

已上傳的文件在文件瀏覽器中以樹狀結構展示，支持按文件夾分組。常見的文件組織方式：

```
SKILL.md
references/           # 參考資料目錄（可選）
  rules.md            # 規則或判斷邏輯
  examples.md         # 典型案例
scripts/              # 腳本目錄（可選）
  calculator.py       # 計算腳本
```

在 SKILL.md 中可以引用這些文件，指示模型在執行時讀取對應內容。

## 下載 Skill

將 Skill 匯出為 .zip 文件，便於備份或在其他工作空間複用。

兩種入口：

- **詳情頁**：點擊右上角下載圖標
- **列表頁**：點擊 Skill 卡片右上角「···」→「下載」

下載的壓縮包包含 SKILL.md 和全部已上傳的文件，結構與上傳時一致。

## 刪除 Skill

在「我的 Skills」列表頁，點擊 Skill 卡片右上角「···」→「刪除」即可刪除。

刪除操作不可撤銷，Skill 的所有內容（包括文件、工具配置）將被永久移除。如果該 Skill 已被某個 Agent 掛載，建議刪除前先解除關聯，避免影響 Agent 的正常運行。
