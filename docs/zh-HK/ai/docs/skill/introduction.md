# Skill 簡介

Skill 是一種可複用的能力單元。你可以將一套完整的任務處理邏輯——包括角色定義、執行步驟、所需工具和參考資料——封裝為一個 Skill，然後在一個或多個 Agent 中調用。

相比將所有指令直接寫在 Agent 的提示詞裡，Skill 的優勢在於複用：同一套邏輯只需定義一次，可以跨 Agent 使用，也便於獨立維護和迭代。

## Skill 的典型應用場景

以下是一些常見的 Skill 使用場景：

**財務分析**：封裝一套解讀財報的分析框架，包括比較實際業績與分析師預期、拆解收入結構、評估盈利質量。任何需要分析財報的 Agent 都可以直接掛載這個 Skill，而不需要重複編寫分析邏輯。

**技術面診斷**：定義一套技術指標分析流程，覆蓋均線趨勢、支撐壓力位、MACD/RSI 等指標的判斷邏輯，讓 Agent 具備標準化的技術分析能力。

**數據可視化**：封裝圖表生成邏輯和格式規範，讓 Agent 在用戶需要圖表時自動調用正確的可視化工具和輸出格式。

## Skill 的組成

一個完整的 Skill 包含以下幾個部分：

| 組成部分               | 是否必需 | 說明                                                       |
| ---------------------- | -------- | ---------------------------------------------------------- |
| SKILL.md               | 必需     | 核心定義文件，包含 Skill 的名稱、描述和執行邏輯            |
| 名稱（name）           | 必需     | Skill 的唯一標識，僅限小寫字母、數字和連字符，最大 64 字符 |
| 描述（description）    | 必需     | 說明該 Skill 的功能及適用場景，供模型判斷何時調用          |
| 工具（tools）          | 可選     | 賦予 Skill 調用外部能力的模組，包括內置工具和 OpenAPI 工具 |
| 參考文件（references） | 可選     | Skill 執行時可訪問的背景資料、規則文件或配置文件           |

## SKILL.md 的作用

SKILL.md 是 Skill 的核心，它用 Markdown 格式定義了模型在執行該 Skill 時的行為規範：角色是誰、按什麼流程工作、遇到什麼情況如何響應。

SKILL.md 文件的開頭需要包含一段 YAML 格式的元數據（frontmatter），聲明該 Skill 的名稱和描述：

```
---
name: your-skill-name
description: 描述此 Skill 的功能及適用場景
---

# Skill 標題

## 角色定義
...

## 執行流程
...
```

## 在 Agent 中使用 Skill

Skill 通過 Agent 節點的 Skills 區域掛載。在 Agent 配置面板中，點擊 Skills 區域右側的「+」，選擇要掛載的 Skill 即可。

Agent 支持兩種掛載方式：

**固定 Skill**

指定一個具體的 Skill，每次運行 Agent 時始終調用該 Skill。適合 Agent 職責單一、任務類型固定的場景。

**動態 Skill**

通過變量值動態指定 Skill，Skill 的選擇由運行時的上下文決定。適合需要根據用戶輸入或流程狀態切換不同 Skill 的場景，例如根據用戶選擇的分析風格調用不同的策略 Skill。
