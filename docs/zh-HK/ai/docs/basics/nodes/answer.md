## 節點概述

**節點英文名**: Answer  
**節點中文名稱**: 輸出答案  
**支援場景**: Chatflow Agent（支援）, Workflow Agent（不支援）  

## 功能說明

Answer 節點用於將節點結果或最終回答輸出給 Chat 系統，常用於結束一次對話或向上層呼叫方提供最終資訊。它是 Chatflow Agent 中的終結節點，負責格式化並輸出最終的回答內容。

## 節點展示內容

### 1. 基本資訊展示
- **圖示**: 節點專用圖示
- **名稱**: 節點名稱
- **輸出模版**: 去除空行後的模版內容預覽
- **註釋**: 使用者新增的說明文字

### 2. 操作按鈕
- **更多按鈕**: 點選後展示右鍵選單內容

## 節點編輯區域

![Answer 節點編輯面板：回覆模版、儲存上下文、長期記憶與輸出變數](./images/02-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. 回覆模版編輯

#### a. 編輯框功能
- **支援插入變數**: 可以在模版中插入各種變數
- **支援輸入字元**: 支援直接輸入文本內容
- **變數選擇**: 輸入"/"喚起選擇變數值的輸入框

#### b. 編輯輔助功能
- **長度統計**: 支援統計模版的長度，變數名稱計入模版長度統計
- **複製功能**: 點選 copy 按鈕複製模版
- **最大化**: 點選最大化按鈕，將模版展示最大化

### 2. 儲存上下文

**儲存上下文功能對於上下文的儲存十分重要**,它可以在 Chatflow 執行結束時儲存本輪上下文供後續會話使用，這個上下文包括了工具呼叫的各種資訊。

- 在此處選擇要儲存的上下文變數，如上圖中選擇了 `LLM/context`(array[context] 型別)
- **如果一個 Chatflow 需要有良好的上下文管理，需要把 LLM 節點或 Agent 節點的上下文 (context) 變數儲存在這裡**——否則下一輪對話時，模型將無法感知本輪的工具呼叫過程與中間結果

![Answer 節點編輯面板：回覆模版、儲存上下文、長期記憶與輸出變數](./images/02-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)


### 3. 長期記憶

- 開啟後，提取的長期記憶會在內容輸出時**同步展示**
- 這不是一個必選的功能，按需開啟即可
- 開啟後，輸出變數區會增加 `user_memory_changes`(array[string] 型別),記錄本輪提取到的長期記憶變更

### 4. 附加資料

- 附加資料功能用於主 Agent 的一些功能的實現
- 一般使用者自己搭建的 Agent 暫時使用不上，後續功能教學會逐步開放

### 5. 輸出變數

- `answer`: String 型別，本節點最終輸出的回答內容
- `user_memory_changes`: array[string] 型別，長期記憶變更記錄 (僅開啟「長期記憶」後出現)

### 6. 下一步配置
- Answer 節點是終止節點，不支援新增下一個節點

## 執行邏輯

Answer 節點的執行邏輯由後端實現，確保答案輸出的正確性。

## 右鍵操作

右鍵選單包含以下選項：
1. **更改節點**: 修改節點型別
2. **複製**: 複製節點
3. **複製**: 複製節點內容
4. **刪除**: 刪除節點
5. **幫助連結**: 跳轉到幫助文件

## 節點數量控制

- **限制**: 一個 Agent 可以有多個 Answer 節點
- **用途**: 可以作為終結節點使用；多個 Answer 節點適用於不同的分支——例如經過條件判斷或問題分類後，各分支走向各自的 Answer 節點，輸出對應的回覆內容

## 測試執行

- **支援狀態**: 不支援測試執行
- **更改節點**: 支援更改節點型別
- **複製功能**: 支援複製、剪貼、刪除操作

## 使用場景

### 1. 對話終結
- 在 Chatflow Agent 中作為對話的最終輸出
- 將 AI 處理的結果以友好的方式展示給使用者

### 2. 結果格式化
- 將複雜的處理結果格式化為使用者可讀的文本
- 支援變數替換，動態生成個性化內容

### 3. 多語言支援
- 支援不同語言的輸出模版
- 可以根據使用者語言偏好調整輸出格式

## 模版編寫技巧

### 1. 直接引用上游節點輸出 (最常用)

大多數場景不需要編寫複雜模版，**直接選擇 LLM 節點或 Agent 節點的輸出變數即可**:

- 在回覆模版編輯框中輸入 `/` 喚起變數選擇，選中上游節點的 `text` 輸出 (如 `LLM/text`)
- 模版裡只放這一個變數，模型生成什麼就原樣輸出什麼，簡單可靠

### 2. Debug 輸出技巧

除錯 Chatflow 時，可以**臨時在模版中加入中間變數**,把流程內部狀態直接列印到回覆裡觀察：

```
【Debug】
分類結果: {{分類節點輸出}}
檢索命中: {{知識檢索輸出}}
---
{{LLM/text}}
```

- 能快速定位問題出在哪個環節：分支走錯、檢索為空還是模型生成異常
- 也可以利用多 Answer 節點的特性，給某個分支單獨掛一個 Debug 用的 Answer 節點，輸出該分支的中間變數
- **除錯完成後記得移除 Debug 內容再發布**,避免內部資訊展示給終端使用者

## 常見問題

### Q: 如何插入變數？
A: 可以通過輸入"/"按鈕來插入變數。

### Q: 模版長度如何計算？
A: 模版長度包括所有文本內容和變數名稱，變數值不計入長度。

### Q: 支援哪些變數型別？
A: 支援 String、Number、Object、Array 等基本資料型別。

### Q: 如何處理空值？
A: 建議在模版中使用條件判斷來處理可能的空值情況。
