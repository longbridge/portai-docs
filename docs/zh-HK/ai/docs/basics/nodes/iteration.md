## 節點概述

**節點英文名**: Iteration  
**節點中文名稱**: 迭代  
**支援場景**: Chatflow Agent（支援）, Workflow Agent（支援）  

## 功能說明

Iteration 節點與迴圈類似，但更注重每次迭代對變數的更新並傳遞給下一輪處理，用於列表、序列或批次資料迭代場景。它提供了強大的迭代處理能力，支援並行模式和錯誤處理。

### 1. 輸入變數配置

- **並行模式開關**: 在編輯面板中開啟

- **忽略錯誤並繼續**: 忽略錯誤繼續執行

## 迭代模式

### 1. 順序迭代
按順序處理每個元素：

```
FOR each item IN input_list:
    處理 item
    更新 output_variables
    傳遞到下一輪
```

### 2. 並行迭代
並行處理多個元素：

```
PARALLEL FOR each item IN input_list:
    處理 item
    更新 output_variables
    合併結果
```

## 錯誤處理策略

### 1. 錯誤時終止
- **特點**: 遇到錯誤立即停止
- **適用場景**: 對資料質量要求高的場景
- **優勢**: 確保資料完整性
- **劣勢**: 可能影響處理效率

### 2. 忽略錯誤並繼續
- **特點**: 忽略錯誤繼續處理
- **適用場景**: 對容錯性要求高的場景
- **優勢**: 提高處理效率
- **劣勢**: 可能影響結果質量

### 3. 移除錯誤輸出
- **特點**: 移除錯誤的輸出結果
- **適用場景**: 平衡質量和效率的場景
- **優勢**: 兼顧質量和效率
- **劣勢**: 需要額外的錯誤檢測

## 常見問題

### Q: 如何選擇並行數量？
A: 根據系統資源和任務特點選擇，範圍是 2-10，建議根據 CPU 核心數設定。

### Q: 錯誤處理策略如何選擇？
A: 根據業務需求選擇，對質量要求高選擇終止，對效率要求高選擇繼續。

### Q: 迭代和迴圈有什麼區別？
A: 迭代更注重變數更新和傳遞，迴圈更注重重複執行，迭代支援並行模式。

### Q: 如何最佳化迭代效能？
A: 使用並行模式，合理設定並行數量，最佳化迭代邏輯，減少不必要的操作。

### Q: 迭代結果如何管理？
A: 通過輸出變數管理迭代結果，支援各種資料型別，可以合併或分別處理。

## 注意事項

1. **並行控制**: 合理控制並行數量，避免資源過度使用
2. **錯誤處理**: 選擇合適的錯誤處理策略
3. **資料質量**: 確保輸入資料的質量和格式
4. **效能考慮**: 考慮迭代對系統性能的影響
5. **結果驗證**: 驗證迭代結果的正確性
