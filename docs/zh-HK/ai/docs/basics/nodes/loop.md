## 節點概述

**節點英文名**: Loop  
**節點中文名稱**: 迴圈  
**支援場景**: Chatflow Agent（支援）, Workflow Agent（支援）  

## 功能說明

Loop 節點按設定的迴圈次數或條件反覆執行同一段邏輯，常用於批次處理或多次迭代。它提供了強大的迴圈控制能力，支援條件迴圈和計數迴圈兩種模式。

## 執行邏輯

### 1. 迴圈執行流程
1. **執行迴圈**: 開始執行迴圈邏輯

## 迴圈型別

### 1. 條件迴圈
基於條件判斷的迴圈：

```
WHILE 條件滿足:
    執行迴圈體
    更新迴圈變數
    檢查中止條件
```

### 2. 計數迴圈
基於迴圈次數的迴圈：

```
FOR i = 1 TO 最大次數:
    執行迴圈體
    更新迴圈變數
    檢查中止條件
```

### 3. 混合迴圈
同時使用條件和計數：

```
FOR i = 1 TO 最大次數:
    IF 條件滿足:
        執行迴圈體
        更新迴圈變數
        檢查中止條件
    ELSE:
        提前退出
```

## 常見問題

### Q: 如何設定迴圈終止條件？
A: 可以設定多個條件，使用 AND/OR 邏輯關係，當條件滿足時迴圈終止。

### Q: 最大迴圈次數如何確定？
A: 根據業務需求和效能考慮設定，範圍是 1-100 次。

### Q: 迴圈變數如何管理？
A: 迴圈變數在迴圈過程中更新，迴圈結束時作為輸出變數。

### Q: 如何避免無限迴圈？
A: 設定合理的終止條件和最大迴圈次數，確保迴圈能夠正常結束。

### Q: 迴圈效能如何最佳化？
A: 最佳化迴圈體邏輯，減少不必要的操作，合理設定迴圈次數。
