## 節點概述

**節點英文名**: Start  
**節點中文名稱**: 開始  
**支援場景**: Chatflow Agent, Workflow Agent  

## 功能說明

Start節點是流程的起始節點，用於初始化流程上下文或進行初始資料準備。它是每個工作流的入口點，負責設定流程的初始狀態和變數。

## 節點展示內容


### 1. 基本資訊展示
- **圖示**: 節點專用圖示
- **名稱**: 節點名稱（預設為"開始"）
- **自定義欄位**: 使用者新增的自定義變數
- **註釋**: 使用者新增的說明文字

### 2. 操作按鈕
- **更多按鈕**: 點選後展示右鍵選單內容

## 節點編輯區域


### 1. 節點圖示和名稱（通用功能）
- **節點圖示**: 顯示節點型別圖示
- **節點名稱**: 建立時按當前語言生成預設名稱，支援修改
- **定位到當前節點**: 點選後快速定位到當前節點
- **幫助文件**: 點選跳轉到Infra幫助文件

### 2. 輸入欄位配置

#### a. 自定義變數
- 支援新增自定義變數：點選「輸入欄位」標題右側的 **+ 按鈕**（位置見下圖紅色箭頭處）
- 自定義變數可以為空
- 變數展示內容包括：
  - 變數的符號
  - 變數名
  - 變數說明
  - 變數型別圖示
  - 必填/非必填圖示

![輸入欄位的新增按鈕位置(+ 號),下方為系統變數列表](./images/01-3-%E8%BE%93%E5%85%A5%E5%AD%97%E6%AE%B5%E6%B7%BB%E5%8A%A0%E6%8C%89%E9%92%AE.png)

> 💡 **兩種應用型別對「輸入欄位」的依賴完全不同:**
>
> - **Chatflow:一般情況下不需要使用**。使用者輸入通過系統變數 `sys.query` 傳入即可。後續 Agent 平臺將開放**正式輸入時輸入框的結構化輸入能力**——屆時使用者可以在對話輸入框中按欄位填寫內容，你在這裡定義的輸入欄位才會真正產生作用。現階段可以直接跳過本配置。
> - **Workflow:強依賴自定義輸入欄位**。Workflow 沒有聊天輸入框,Start 節點的自定義欄位就是整個流程的**輸入引數**(由 API 呼叫方或觸發器傳入),必須在這裡定義清楚欄位名、型別和是否必填,下游節點才能引用。開啟觸發器模式後,輸入變數會切換為觸發器定義的欄位(見 [Workflow 觸發器](../capabilities/workflow-triggers))。

#### b. 預設變數（系統變數）
- `sys.query`: String型別（僅Chatflow Agent存在且為預設值），這個是最關鍵的輸入變數。後面要用到。
- `sys.language`: String型別（僅Chatflow Agent存在且為預設值）
- `sys.user_id`: String（系統變數，不可移除）
- `sys.app_id`: String（系統變數，不可移除）
- `sys.workflow_id`: String（系統變數，不可移除）
- `sys.workflow_run_id`: String（系統變數，不可移除）
  作為使用者不太需要知道其他系統變數是啥含義，這裡不做贅述

### 3. 安全與合規開關

![安全與合規開關配置區,含輸出變數與下一步區域](./images/01-4-%E5%AE%89%E5%85%A8%E5%90%88%E8%A7%84%E5%BC%80%E5%85%B3.png)

Start 節點提供四個安全與合規相關的開關,預設均為關閉狀態:

#### a. 隱藏個人身份資訊
- 開啟後,系統將自動識別使用者輸入中的**個人身份資訊(PII)**,並以星號(`*`)替換
- 被隱藏的資訊在後續會話中將**不再展示**
- 開啟後,輸出變數區會提供 `pii_flagged`(Boolean 型別)——個人身份資訊檢查標記,供下游節點判斷本次輸入是否命中了 PII 識別

#### b. 遮蔽不良內容
- 開啟後,系統將自動識別使用者輸入中涉及**仇恨、騷擾、自殘、暴力、色情、未成年人相關、違法及其他高風險內容型別**
- 一旦檢測到相關內容,系統將**阻斷響應**,不再繼續處理或返回結果

#### c. 遮蔽不良的金融領域內容
- 開啟後,系統將依據適用的法律法規、監管要求及平臺合規與風險控制規則,對使用者輸入內容進行自動識別與稽核
- 如檢測到涉及**非法交易建議**的內容,包括但不限於:
  - 洗錢(如隱匿資金來源、分層交易、拆分交易)
  - 逃稅、證券欺詐、內幕交易、市場操縱
  - 恐怖融資或規避制裁
  - 使用被盜或偽造的身份、賬戶或支付工具進行交易
  - 其他明顯違法或被禁止的交易行為及金融犯罪
- 系統將**阻斷相關響應並終止後續處理**

#### d. 強制交易密碼校驗
- **內部用途**開關,不推薦普通使用者使用

### 4. 輸出變數

- `pii_flagged`: Boolean 型別,個人身份資訊檢查標記(配合「隱藏個人身份資訊」開關使用,見上文)

### 5. 下一步配置
- **展示連線的下個節點**: 
  - 滑鼠懸停狀態，展示跳轉到節點和更多選項
  - 更多功能包括：
    - 點選更改：展示新增節點的功能
    - 點選刪除：刪除下一個節點
    - 點選斷開連結：斷開和下個節點的連線
- **新增並行節點按鈕**: 點選後展示新增節點的功能

### 6. 關閉視窗（通用功能）

## 執行邏輯

Start節點的執行邏輯由後端實現，確保流程的正確執行。

## 右鍵操作

右鍵選單包含以下選項：
1. 幫助連結

> Start 節點是工作流的唯一入口,**不支援**更改節點、複製、複製、刪除操作。

## 節點數量控制

- **限制**: 只能有一個Start節點
- **用途**: 作為工作流的唯一入口點

## 測試執行

- **支援狀態**: 支援測試執行
- **更改節點**: 不支援
- **複製功能**: 不支援複製、剪貼、刪除


## 使用建議

1. **變數規劃**: 在Start節點中預先定義好整個流程需要的變數
2. **命名規範**: 為自定義變數使用清晰的命名規範
3. **必填設定**: 合理設定變數的必填/非必填屬性
4. **流程設計**: 確保Start節點連線到合適的下一個節點

## 注意事項

- Start節點是工作流的必需節點，每個工作流必須有且僅有一個
- 系統變數不可刪除，確保流程正常執行
- 自定義變數可以根據業務需求靈活配置
- 建議在Start節點中完成所有必要的初始化工作
