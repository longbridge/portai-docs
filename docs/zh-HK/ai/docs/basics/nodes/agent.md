## 快速參考

> Agent 節點**沒有策略選擇**,預設均為 **Function Calling 模式**(模型通過函式呼叫來使用工具,迴圈執行直到任務完成)。

## 功能說明

**Agent 節點是平臺最核心的節點之一**。它的本質是一個 **LLM 的迴圈**:LLM 在迴圈中自主決定下一步動作,直到任務完成,可以完成各種複雜度較高的功能,包括:

- **規劃**: 拆解任務,決定執行步驟
- **回答問題**: 生成回覆內容
- **呼叫工具**: 使用掛載的工具獲取資訊或執行操作
- **使用 Skill**: 呼叫掛載的 Skill 完成專項任務
- **開啟沙盒**: 在沙盒環境中執行程式碼
- **執行指令碼**: 執行指令碼處理資料或邏輯
- **執行 HITL**: 人機協作(Human-in-the-Loop),在關鍵步驟引入人工確認

此外還支援:
- **工作流整合**: 呼叫已有Agent Tool，支援多步對話和業務處理

#### c. 工具搜尋

![工具搜尋開關](./images/05-4-%E5%B7%A5%E5%85%B7%E6%90%9C%E7%B4%A2.png)

### 6. 功能開關

Agent 節點提供一組能力開關,按需開啟:

#### a. 使用者標籤

- 開啟後,LLM 會在**需要個性化回答的場景**下讀取當前使用者的**畫像標籤與偏好標籤**——例如投資目標、風險偏好、分析風格和其他個性化興趣/不感興趣項

#### b. 知識庫

![知識庫開關](./images/05-7-%E7%9F%A5%E8%AF%86%E5%BA%93.png)

- 開啟「知識庫」後,AI 將在必要時搜尋所選知識庫

#### c. 人機互動(HITL)

![人機互動開關](./images/05-6-%E4%BA%BA%E6%9C%BA%E4%BA%A4%E4%BA%92.png)

- 允許模型在執行過程中**向用戶提問並等待回答**
- 這個功能很強,**建議開啟**

#### d. 聯網搜尋

![聯網搜尋開關](./images/05-8-%E8%81%94%E7%BD%91%E6%90%9C%E7%B4%A2.png)

- 開啟「聯網搜尋」後,AI 將在必要時使用內建網路搜尋工具
- **強烈建議開啟**

#### e. 待辦事項

- 開啟「待辦事項」後,AI 將自動識別對話中的任務並**拆解和執行**
- **強烈建議開啟**

#### f. 輸出內容合法合規檢查

- 開啟後,系統將在輸出時對內容進行**合規校驗**
- 如識別到輸出內容存在不合法或不符合金融合規要求的情形,系統將**立即停止輸出並清空已生成的內容**

### 7. 最大迭代次數
- **範圍**: 1-99次配置
- **用途**: 控制Agent的最大執行次數
- **建議值**: 一般建議設定為 **99 次**,給 Agent 足夠的迴圈空間完成複雜任務

### 8. 輸出變數
- **text**: agent生成的內容（text）
- **think**: 模型的思考過程。**部分模型支援 think 輸出**，可以使用「思考過程輸出」（僅Chatflow支援）的節點輸出
- **agent生成的json**: 結構化輸出結果

### 9. 下一步配置
- 支援新增下一個節點

## 執行模式說明

Agent 節點統一採用 **Function Calling 模式**執行,無需選擇策略:

- **特點**: 模型通過函式呼叫使用預定義的工具,在迴圈中自主規劃、呼叫、判斷,直到任務完成
- **優勢**: 精確控制,可預測性強,同時具備處理複雜多步任務的能力

## 常見問題

### Q: Agent節點需要選擇執行策略嗎？
A: 不需要。Agent節點沒有策略選擇，預設均為Function Calling模式。

### Q: 如何新增工具？
A: 點選新增工具按鈕，從工具列表中選擇需要的工具。

### Q: 最大迭代次數如何設定？
A: 範圍是1-99次，一般建議設定為99次，給Agent足夠的迴圈空間完成複雜任務。

### Q: Agent如何選擇工具？
A: Agent會根據任務需求和工具能力自動選擇合適的工具。

### Q: 如何最佳化Agent效能？
A: 合理配置工具（工具較多時開啟工具搜尋）、設定適當的迭代次數。
