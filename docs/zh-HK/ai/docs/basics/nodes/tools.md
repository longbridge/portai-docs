## 節點概述

**節點英文名**: Tool(以所選工具的英文名為準)  
**節點中文名稱**: 工具 (畫布上顯示所選工具各自的名稱)  
**支援場景**: Chatflow Agent（支援）, Workflow Agent（支援）  

## 功能說明

Tool 節點觸發對外部工具（包括長橋內和長橋外）的呼叫，將呼叫結果反饋到流程中以供後續節點使用。它提供了強大的工具整合能力，支援各種外部工具和服務的呼叫。

**新增方式**：點選畫布左下角的節點面板，切換到「工具」頁籤（可在 Infra / OpenAPI 來源間切換），按分類（資訊與社群內容、即時行情、技術分析與選股等）或搜尋找到目標工具，點選即可新增到畫布：

## 節點編輯區域

![工具節點編輯面板：工具說明、輸入變數 (含型別/必填/說明，變數引用或直接設值)、展示配置與引用開關、輸出變數 text/data、失敗時重試、異常處理、下一步節點](./images/14-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. 工具說明
- 面板頂部展示工具名稱與功能說明（如「獲取新聞詳情（批次）：按 ID 批次獲取新聞詳情」）

### 2. 輸入變數
- **引數定義**: 按工具入參逐項展示——引數名、型別（如 array）、是否必填、引數說明（如「要獲取詳情的 ID 列表，最大長度為 20」）
- **取值方式**: 選擇「變數」引用上游變數，或直接設定固定值

### 3. 展示配置與引用
- **展示配置**: 開關，控制工具結果在對話端的展示方式
- **引用**: 開關，控制回答中是否攜帶該工具結果的引用來源

### 4. 輸出變數
- **text** (string): 工具生成的文本內容
- **data** (object): 工具生成的結構內容

### 5. 容錯配置
- **失敗時重試**: 開關，呼叫失敗時自動重試
- **異常處理**: 下拉選擇異常處理策略（預設「無」）

### 6. 下一步配置
- 支援新增下一個節點

## 執行邏輯

Tool 節點的執行邏輯由後端實現，確保工具呼叫的正確性和安全性。

5. **幫助連結**: 跳轉到幫助文件

## 工具來源與分類

- **來源**: **Infra 內建工具** / **OpenAPI 自定義工具**（節點面板「工具」頁籤內切換；第三方 MCP 工具見 Agent 節點與套餐說明）
- **Infra 內建分類**: 資訊與社群內容、即時行情、技術分析與選股、基本面與財務資料、宏觀經濟資料、AI 分析與訊號、資料視覺化圖表、賬戶與持倉、訂單管理、基礎工具與搜尋、使用者記憶與個性化、幫助文件
- 可用工具範圍隨**套餐與地區**變化（內建工具 Starter 為部分、Pro 及以上全量）

## 使用場景

### 1. 行情與資訊
- 獲取即時行情、股票相關新聞 / UGC 內容，交給 LLM 總結解讀（先查後答，見 2.3 模式 3）

### 2. 技術分析
- 獲取 K 線等資料後交給 Code 節點計算指標（大數據量計算不要交給模型，見 2.5 技巧三）

### 3. 賬戶場景
- 查詢賬戶與持倉、訂單資訊（面向客戶時注意合規邊界，不構成投資建議）

### 4. 視覺化
- 呼叫圖表類工具，在對話端展示視覺化結果

## 配置步驟

1. 在節點面板「工具」頁籤中按分類或搜尋新增工具
2. 配置輸入變數（引用上游變數或設定固定值，必填項不可缺）
3. 按需開啟展示配置 / 引用、失敗時重試與異常處理
4. 試執行驗證結果，連線下一個節點

## 常見問題

### Q: 工具執行失敗怎麼辦？
A: 檢查必填輸入引數是否配置正確，用試執行檢視報錯；開啟失敗時重試並配置異常處理策略。

### Q: 為什麼找不到某個工具？
A: 可用工具範圍隨套餐與地區變化（如內建工具 Starter 僅部分可用），詳見 Workspace 與套餐體系文件。

### Q: 工具輸出怎麼在後續節點使用？
A: `text` 適合直接給 LLM / Answer 節點引用；`data` 結構化內容適合給 Code、IF Else 等節點加工判斷。

### Q: 工具呼叫計費嗎？
A: 僅特定搜尋和爬蟲類工具按呼叫次數計費，其餘不計費，詳見套餐與用量說明。

## 注意事項

1. **必填引數**: 必填輸入變數未配置會導致執行失敗
2. **資料真實性**: 提示詞中要求 LLM 只基於工具返回的資料作答，不得編造
3. **合規邊界**: 面向客戶的場景注意輸出合規（不構成投資建議）
4. **容錯配置**: 重要流程配置失敗重試與異常處理
