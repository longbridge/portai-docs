## 節點概述

**節點英文名**: End  
**節點中文名稱**: 結束  
**支援場景**: Chatflow Agent（不支援）, Workflow Agent（支援）  

## 功能說明

End節點用於終止當前流程的執行，可攜帶處理結果或狀態資訊，通常在所有邏輯處理完成後使用。它是Workflow Agent中的終結節點，以 JSON 方式輸出最終結果。

### 2. 操作按鈕
- **更多按鈕**: 點選後展示右鍵選單內容

## 節點編輯區域


### 1. 輸出變數配置

#### a. 變數管理
- **初始狀態**: 剛建立時，展示空白的一行
- **新增變數**: 點選加號按鈕，新增一行新的輸出變數
- **刪除變數**: 點選刪除按鈕，減少一行變數
- **變數數量**: 輸出欄位至少1個，最多50個

#### b. 變數配置
- **變數名稱**: 輸出變數名稱，不同行之間不可以重複，變數名不可以非字母開頭，變數名只能包含英文數字和下劃線
- **重複檢查**: 重複時展示文案："重複的輸出變數"
- **變數值**: 點選變數值，展現【選擇變數值】功能
- **變數選擇**: 支援從工作流中選擇已有的變數作為輸出

### 2. 下一步配置
- **無下一步**: End節點作為終結節點，不支援連線下一個節點

## 執行邏輯

End節點的執行邏輯由後端實現，確保流程的正確終結。

## 右鍵操作

右鍵選單包含以下選項：
1. **更改節點**: 修改節點型別
2. **複製**: 複製節點
3. **複製**: 複製節點內容
4. **刪除**: 刪除節點
5. **幫助連結**: 跳轉到幫助文件

## 節點數量控制

- **限制**: End節點可以有多個
- **用途**: 可以作為終結節點使用

## 測試執行

- **支援狀態**: 不支援測試執行
- **更改節點**: 支援更改節點型別
- **複製功能**: 支援複製、剪貼、刪除操作

## 使用場景

### 1. 工作流終結
- 在Workflow Agent中作為工作流的最終輸出
- 將處理結果以結構化資料的形式輸出

### 2. 資料輸出
- 以JSON格式輸出處理結果
- 便於後續系統或API呼叫

## 輸出格式示例

### 1. JSON格式輸出
```json
{
  "b": "a"
}
```

## 最佳實踐

### 1. 變數命名
- **語義化**: 使用有意義的變數名稱
- **一致性**: 保持命名規範的一致性
- **避免重複**: 確保變數名稱不重複

### 2. 輸出結構
- **結構化**: 使用清晰的資料結構
- **標準化**: 遵循行業標準的資料格式
- **可擴充套件**: 設計可擴充套件的輸出結構

### 3. 錯誤處理
- **狀態碼**: 包含處理狀態資訊
- **錯誤資訊**: 提供詳細的錯誤描述
- **除錯資訊**: 包含必要的除錯資訊

## 配置步驟

### 1. 新增輸出變數
1. 點選"+"按鈕新增新的輸出變數
2. 輸入變數名稱（確保唯一性）
3. 選擇變數值來源

### 2. 配置變數值
1. 點選變數值欄位
2. 從變數選擇器中選擇合適的變數
3. 確認配置

### 3. 驗證配置
1. 檢查變數名稱是否重複
2. 確認變數值是否正確
3. 驗證輸出格式是否符合要求

## 注意事項

1. **變數唯一性**: 確保所有輸出變數名稱唯一
2. **數量限制**: 輸出變數數量在1-50個之間
3. **終結節點**: End節點不支援連線下一個節點
4. **資料格式**: 注意輸出資料的格式和型別

## 常見問題

### Q: 如何新增輸出變數？
A: 點選"+"按鈕可以新增新的輸出變數行。

### Q: 變數名稱重複怎麼辦？
A: 系統會提示"重複的輸出變數"，需要修改為唯一的名稱。

### Q: 最多可以新增多少個輸出變數？
A: 最多可以新增50個輸出變數。

### Q: End節點可以連線下一個節點嗎？
A: 不可以，End節點是終結節點，不支援連線下一個節點。

### Q: 如何選擇變數值？
A: 點選變數值欄位，會彈出變數選擇器，可以選擇工作流中的任意變數。
