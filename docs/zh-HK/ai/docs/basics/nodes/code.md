## 節點概述

**節點英文名**: Code  
**節點中文名稱**: 程式碼執行  
**支援場景**: Chatflow Agent（支援）, Workflow Agent（支援）  
**迭代版本**: 版本1  

## 功能說明

Code節點用於執行一段自定義程式碼（如Python和JavaScript），實現特定業務邏輯或計算，輸出結果供後續節點使用。它提供了強大的程式設計能力，允許使用者在工作流中執行自定義的程式碼邏輯。

## 節點編輯區域

![程式碼執行節點編輯面板:輸入變數(arg1/arg2)、PYTHON3程式碼編輯器(main函式)、輸出變數(result)與失敗時重試](./images/11-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. 輸入變數配置
- **新增變數**: 點選後新增一行輸入變數
- **變數列表**: 支援多行變數的展示，支援刪除
- **變數輸入**: 支援多個變數的輸入
- **變數名**: 支援填寫變數名稱
- **變數值**: 支援通過【選擇變數】元件選擇變數值

### 2. 程式碼輸入框
- **語言選擇**: 支援Python3和JavaScript兩種型別的選擇
- **程式碼編輯**: 提供程式碼編輯器，支援語法高亮、複製與放大
- **固定入口**: 程式碼需實現 `main` 函式，返回值為字典，鍵與輸出變數一一對應（如 `def main(arg1: str, arg2: str) -> dict: return {"result": arg1 + arg2}`）

### 3. 輸出變數配置
- **變數名稱**: 支援填寫變數名稱
- **變數型別**: 支援選擇變數型別
- **新增刪除**: 支援新增和刪除變數
- **變數類型範圍**:
  - String / Array[String]
  - Number / Array[Number]
  - Object / Array[Object]

### 4. 失敗時重試
- **開關**: 開啟後，程式碼執行失敗時自動重試

### 5. 下一步配置
- 支援新增下一個節點

## 執行邏輯

Code節點的執行邏輯由後端實現，確保程式碼的正確執行和安全控制。

## 右鍵操作

右鍵選單包含以下選項：
1. **更改節點**: 修改節點型別
2. **複製**: 複製節點
3. **複製**: 複製節點內容
4. **刪除**: 刪除節點
5. **幫助連結**: 跳轉到幫助文件
6. **執行節點**: 測試運行當前節點

## 測試執行

- **支援狀態**: 支援測試執行
- **更改節點**: 支援更改節點型別
- **複製功能**: 支援複製、剪貼、刪除操作

## 程式語言支援

### 1. Python3
- **版本**: Python 3.x
- **標準庫**: 支援Python標準庫（第三方庫以沙箱實際支援為準）
- **語法**: 完整的Python語法支援

### 2. JavaScript

![JS模式:語言切換為JAVASCRIPT,main函式以解構物件接收輸入變數](./images/11-3-JS%E6%A8%A1%E5%BC%8F.png)

- **版本**: Node.js環境
- **標準庫**: 支援Node.js標準庫
- **語法**: 完整的JavaScript語法支援
- **函式簽名**: 與 Python 模式不同,JS 的 `main` 函式以**解構物件**接收輸入變數——`function main({arg1, arg2})`,返回物件的欄位對應輸出變數(如 `return { result: ... }`)

## 常見問題

### Q: 支援哪些程式語言？
A: 目前支援Python3和JavaScript兩種程式語言。

### Q: 如何新增輸入變數？
A: 點選"+"按鈕可以新增新的輸入變數行。

### Q: 輸出變數型別有哪些？
A: 支援String、Number、Object及其對應的Array型別。

### Q: 程式碼執行有安全限制嗎？
A: 是的，程式碼執行有安全限制，不能執行危險操作。

### Q: 如何除錯程式碼？
A: 可以使用試執行功能來除錯程式碼，檢視執行結果。
