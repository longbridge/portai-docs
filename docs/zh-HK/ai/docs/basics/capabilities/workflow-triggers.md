> ⚠️ Workflow 使用門檻較高，**暫未對普通使用者開放**,本篇供提前瞭解，開放時間以產品公告為準。

## 是什麼

為 Workflow 配置自動觸發方式，無需手動執行 —— 讓 Agent 按**定時器**或 **Webhook** 自動執行，實現無人值守的自動化任務 (晨間簡報、定期巡檢、外部系統聯動等)。

## 兩種觸發方式

### 定時觸發

- 填寫 **Cron 表示式**並選擇時區
- 面板**即時預覽接下來 5 次執行時間**,寫完表示式立刻能確認對不對

### Webhook 觸發

- 系統生成 Webhook URL，複製後提供給外部系統即可
- 可配置接收的請求引數 (**Headers、Query、Body**) 及響應內容
- 外部系統呼叫 URL 即觸發 Workflow 執行

## 使用步驟

1. 開啟 Workflow 編輯器，點選 Start 節點，點選頂部 **Trigger Mode** 開啟觸發器模式
2. 在面板中開啟「定時觸發」或「Webhook 觸發」並完成配置
3. **除錯**:點選執行按鈕，下拉選單中選擇對應 trigger 進入除錯模式，釋出前驗證觸發效果
4. 除錯確認後**釋出** Workflow，觸發器即刻生效自動排程

## 注意事項

1. 開啟觸發模式後，**Start 節點的輸入變數會切換為觸發器定義的欄位**,關閉後恢復原有變數
2. 定時觸發和 Webhook 觸發**可同時啟用**,互不影響
3. Webhook 為**非同步執行**:外部請求會立即收到配置的響應，Workflow 在後臺執行 —— 外部系統不要依賴響應體獲取執行結果
4. **試執行連結與釋出後的生產連結不同**,對接外部系統時務必使用生產連結
5. 自動觸發的運行同樣消耗 Workspace 用量額度，定時任務上線前先估算頻率 × 單次消耗，避免額度被靜默耗盡 (見 [Workspace 與套餐體系](../plans))
