## 是什麼

把你的本地文件上傳到平臺,經解析、分塊、向量化後供 Agent 檢索使用 —— 讓 Agent 基於**你的私有知識**作答,而不是隻靠模型的通用知識。典型場景:產品 FAQ 客服、內部制度問答、研究資料輔助分析。

![知識庫首頁:空態時的「建立知識庫」入口](./images/01-1-%E7%9F%A5%E8%AF%86%E5%BA%93%E9%A6%96%E9%A1%B5.png)

## 建立流程(四步)

1. **建立知識庫**:填寫名稱、描述,選擇檢索設定。支援三種檢索方式:
   - **混合檢索**(推薦預設):向量 + 全文結合
   - **向量檢索**:語義相似度匹配,適合口語化提問
   - **全文檢索**:關鍵詞精確匹配,適合術語、程式碼、編號類查詢
   - 也可點選「建立空白知識庫」先建庫、後續再補檔案

   ![建立知識庫:名稱、描述與檢索設定(混合檢索為推薦預設)](./images/01-2-%E5%88%9B%E5%BB%BA%E7%9F%A5%E8%AF%86%E5%BA%93.png)

2. **上傳檔案**:拖拽或選擇檔案,每次最多 5 個、單個不超過 10MB;支援 DOCX、PPTX、HTML、PDF、MD、CSV、XLSX、VTT、JPG、PNG、TXT

   ![上傳檔案:拖拽或選擇,支援格式與大小限制說明](./images/01-3-%E4%B8%8A%E4%BC%A0%E6%96%87%E4%BB%B6.png)

   ![已上傳檔案列表:大文件可拆分為多個檔案分批上傳(示例為一本書按頁碼區間拆成4個PDF)](./images/01-4-%E6%96%87%E4%BB%B6%E5%B7%B2%E4%B8%8A%E4%BC%A0.png)

3. **文本設定**:按檔案型別自定義分段長度(預設 1024 字元)、文本預處理規則(替換連續空格換行/刪除 URL 與郵箱)、**分段語義增強**(啟用圖片內容理解 vlm),並點選「預覽塊」**預覽分塊效果** —— 分塊質量直接決定檢索質量,值得在這一步多花時間

   ![文本設定:分塊長度、預處理規則、語義增強與分塊預覽](./images/01-5-%E6%96%87%E6%9C%AC%E8%AE%BE%E7%BD%AE.png)

4. **處理並完成**:檢視嵌入處理進度(每個檔案獨立顯示步驟與百分比),下方彙總本次的分段模式、分塊長度、預處理規則與檢索設定;可直接「轉到文件列表頁」,處理在後臺繼續

   ![處理並完成:嵌入處理進度與配置彙總](./images/01-6-%E5%A4%84%E7%90%86%E5%B9%B6%E5%AE%8C%E6%88%90.png)

## 日常管理

- **知識庫列表**:知識庫 tab 以卡片展示全部知識庫(檢索方式、文件數、更新時間),頂部展示**容量使用進度**;卡片右上角「…」進入管理操作

  ![知識庫列表頁:容量進度條與知識庫卡片](./images/01-7-%E7%9F%A5%E8%AF%86%E5%BA%93%E5%88%97%E8%A1%A8.png)

- **文件列表**(知識庫詳情頁):按處理狀態篩選、按名稱搜尋;展示字元數、**召回次數**(哪些文件真正被用到)、上傳時間與狀態(如「索引中」);每個文件支援啟用/停用開關與更多操作,右上角可繼續「新增檔案」

  ![知識庫詳情頁:文件列表與狀態、啟用開關](./images/01-8-%E6%96%87%E6%A1%A3%E5%88%97%E8%A1%A8.png)

- **知識庫設定**:修改知識庫的名稱、描述與**檢索設定**(混合/向量/全文可隨時切換,混合檢索支援進階設定調整權重)

  ![知識庫設定頁:名稱、描述與檢索設定修改](./images/01-9-%E7%9F%A5%E8%AF%86%E5%BA%93%E8%AE%BE%E7%BD%AE.png)

- **分段編輯**:點進單個文件可檢視最終給到大模型的分塊內容,支援對具體段落再編輯、編輯關鍵詞;「新增分段」可在文件首段插入自定義內容並配關鍵詞
- **召回測試**:見下節

## 召回測試

入口在知識庫詳情頁右上角(新增檔案按鈕左側)。左側輸入**源文本**(上限 200 字元)、確認檢索方式,點選「測試」:

![召回測試:源文本輸入、檢索方式與測試按鈕](./images/01-10-%E5%8F%AC%E5%9B%9E%E6%B5%8B%E8%AF%95.png)

右側展示命中的**召回塊**:每塊顯示分塊序號、字元數與**相關性分數**(如 0.67),用於判斷檢索質量:

![召回測試結果:命中3個召回塊,展示分塊資訊與分數](./images/01-11-%E5%8F%AC%E5%9B%9E%E6%B5%8B%E8%AF%95%E7%BB%93%E6%9E%9C.png)

- 召回塊底部標註**來原始檔**,可確認內容出自哪份文件
- 左下「記錄」列表保留歷史測試(檢索方法、query、時間),方便換檢索方式對同一 query **對比效果**
- 建議用"使用者真實會問的問題"做 query,而不是文件裡的原句——原句召回分數天然偏高,測不出真實效果

![召回測試記錄:歷史query列表,召回塊底部標註來原始檔](./images/01-12-%E5%8F%AC%E5%9B%9E%E6%B5%8B%E8%AF%95%E8%AE%B0%E5%BD%95.png)

## 在流程中使用

兩個掛載位置,均由 Agent 在**必要時自動檢索**所選知識庫:

**① Agentic Chat**:Agent 配置頁的「知識庫」區,點「+ 新增知識庫」掛載(與 Skills 區相鄰,參考 [1.7.2 Skill 體系](skill) 的配置頁截圖)。

**② Chatflow / Workflow 的 Agent 節點**:節點編輯面板中開啟「知識庫」開關,點 `+` 選擇要掛載的知識庫:

![Agent節點:知識庫開關開啟後出現選擇入口](./images/01-13-Agent%E8%8A%82%E7%82%B9%E7%9F%A5%E8%AF%86%E5%BA%93%E5%BC%80%E5%85%B3.png)

選好後以標籤形式展示(可掛多個):

![Agent節點:已掛載「投資書籍知識庫」](./images/01-14-Agent%E8%8A%82%E7%82%B9%E7%9F%A5%E8%AF%86%E5%BA%93%E5%B7%B2%E9%80%89.png)

### 寫好描述,方便 Agent 召回

Agent 依靠知識庫的**名稱與描述**判斷"什麼問題需要查這個庫"——描述要寫清**覆蓋的內容範圍**(如"投資知識庫,目前包括期權的相關資料"),Agent 遇到期權類問題時才知道該來檢索;描述含糊或缺失會導致該召回時不召回:

![知識庫設定:描述寫清內容範圍,方便Agent判斷何時召回](./images/01-15-%E9%85%8D%E7%BD%AE%E7%9F%A5%E8%AF%86%E5%BA%93%E6%8F%8F%E8%BF%B0.png)

### 執行時的召回效果

配置完成後,使用者提問命中知識庫覆蓋範圍時,Agent 會自動檢索:**推理過程**中展示「知識庫檢索」步驟(含檢索詞),回答正文中以 `Document +N` 標記標註引用來源:

![對話中提問期權問題,推理過程顯示知識庫檢索步驟,回答帶Document引用標記](./images/01-16-%E5%AF%B9%E8%AF%9D%E4%B8%AD%E7%9F%A5%E8%AF%86%E5%BA%93%E5%8F%AC%E5%9B%9E.png)

點開「知識庫檢索」步驟可檢視**請求/響應詳情**——請求包含目標知識庫與檢索詞,響應展示每個命中分塊的內容、相關性分數(score)與排名(rank),可用於排查召回質量:

![知識庫檢索詳情:請求(dataset_uids/query)與響應(分塊content/score/rank)](./images/01-17-%E7%9F%A5%E8%AF%86%E5%BA%93%E6%A3%80%E7%B4%A2%E8%AF%A6%E6%83%85.png)

提示詞中應明確"僅基於檢索到的內容作答,檢索不到時如實說明",避免模型編造。

## 注意事項

1. **容量隨套餐**:Starter 50MB / Pro 5GB / Premium 20GB;超限後禁止新增,超限檔案按上傳時間從最舊開始標記為停用(不參與檢索),刪檔案或升級可恢復 —— 詳見 [1.5 Workspace 與套餐體系](../plans)
2. **Embedding 計費**:文件向量化按 token 消耗用量額度
3. **合規**:面向客戶的知識庫內容須來自合規來源,不得包含 PII 和未公開重大資訊,見 [資料使用與隱私限制](../../compliance/index)
4. 上線前用召回測試跑一遍典型問題,確認檢索質量再發布
