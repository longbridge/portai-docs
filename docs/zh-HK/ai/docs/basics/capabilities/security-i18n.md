## 交易密碼校驗

**是什麼**:當流程中包含**涉及使用者資產資料獲取**的工具 (賬戶資訊、持倉、盈虧等) 時，執行 Workflow 或與該類 Chatflow 對話會自動彈出**交易密碼校驗彈窗**,校驗通過後才能獲取資產資料。

**對搭建者意味著什麼**:

- 鑑權由平臺統一處理，**無需額外開發**,Web 端與 App 端均已適配
- Chatflow 中涉及使用者鑑權的工具**所有套餐均可使用**,鑑權與套餐等級無關，使用者執行時按需完成授權即可
- Workflow 為自動化執行場景，無法在執行時完成互動式鑑權，因此 Workflow 編輯器中**不展示需要使用者鑑權的工具**

**合規意義**:資產資料屬於敏感資料，交易密碼校驗保證了"資料只給驗證過身份的本人"——這也是使用賬戶/持倉/盈虧類 MCP 工具 (見 [模型與工具生態](model-tool-ecosystem)) 的前置條件。

## Answer 輸出簡繁自動轉換

**是什麼**:在 Chatflow 畫布後臺開啟**中文簡/繁轉換**後，Answer 節點輸出的內容會根據**使用者的系統語言**自動進行簡體 ↔ 繁體轉換。

**為什麼重要**:平臺服務香港、新加坡等多地區使用者 (見 [分地區服務說明](../regions)),開啟後無需為簡繁維護兩套提示詞或兩個 Agent，一份流程自動適配。

**使用建議**:面向 HK 使用者的 Chatflow 建議預設開啟;開啟後用簡繁兩種系統語言各測一遍輸出效果。
