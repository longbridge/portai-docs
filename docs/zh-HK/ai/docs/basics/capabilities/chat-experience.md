> 官方 Chatbot 體系與 Agent Platform 共同構成長橋的 AI 產品，**使用者的用量額度在兩者間通用**。本篇介紹 Chatbot 側的能力，**Agent 搭建者瞭解即可**:你的 Agent 釋出後，使用者在這些能力的加持下與它互動。

## 呈現與互動

| 能力 | 說明 |
|------|------|
| **會話圖表** | 結構化投資資料在對話中以專業圖表直觀呈現，趨勢/對比一目瞭然;圖表可互動，使用者可圍繞同組資料繼續追問 |
| **股票行情 / 清單 Widget** | 對話中的行情卡片與股票清單元件;Stock Card 支援分享截圖 |
| **思考鏈與引用** | 思考鏈分階段展示、支援多形態切換;引用以可點選的網站連結形式展示 |
| **回答重試分支** | 重試後按分支切換檢視不同次執行的回答，方便對比 |
| **語音輸入** | 像聊天一樣開口提問，複雜長句一口氣講清 |

## 記憶與個性化

| 能力 | 說明 |
|------|------|
| **長期記憶** | 觸發長期記憶時顯式提示已記住的內容，支援快捷入口管理全部記憶 |
| **歷史聊天記錄檢索** | 對話自動落庫並定期生成摘要;使用者問"上次/之前/以前給你的格式"時，AI 自動檢索歷史對話完成回憶 —— **以使用者為維度，跨 Agent 生效** |
| **使用者標籤** | 使用者可主動維護個性化要求，AI 對話前檢索標籤生成個性化回覆 |
| 個性化問題推薦 | 基於熱門股票池的真實技術面/新聞/社群熱議生成推薦問題，熱度越高更新越快 |
| 推薦問句與追問 | 推薦問句支援「換一換」;追問基於近幾輪問答動態生成 |

> 說明:「個性化問題推薦」與「推薦問句與追問」**僅在官方 Chatbot 中生效，與你搭建的 Agent 無關**——你的 Agent 展示給使用者的引導問題，由設定項中的「Agent 預設問題」自行配置 (見 [設定項](../chatflow-agenticchat-settings))。

## 對搭建者的啟示

1. **輸出結構化資料有紅利**:核心資料以結構化形式輸出，C 端會自動以圖表/Widget 呈現，體驗遠好於純文本 (見 [結構化輸出](../../tutorials/variables-dataflow))
2. **回答風格：結論前置、去廢話** —— 你的 Agent 提示詞同樣適用這套原則 (見 [提示詞編寫技巧](../../tutorials/prompt-writing))
3. **個性化由平臺層完成**:使用者標籤、歷史記憶在平臺層生效，Agent 無需自建使用者畫像 —— 也**不應**自建，見 [資料使用與隱私限制](../../compliance/index)
