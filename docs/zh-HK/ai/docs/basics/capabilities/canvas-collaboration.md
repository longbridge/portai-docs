圍繞畫布操作和團隊協作的一組效率能力，單項都不大，組合起來顯著降低搭建成本。

## 畫布與配置操作

| 能力 | 說明 |
|------|------|
| **多選節點批次操作** | 按住 Shift 後滑鼠框選，批次移動/刪除 |
| **節點複製貼上** | 配好的節點直接複製，不用重新配置 |
| **跨 Agent 複製節點** | 在 A Agent 裡調好的節點可直接貼上到 B Agent —— 沉澱"節點級最佳實踐"的利器 |
| **Tool 自定義名稱 + 多語言** | Agent Tool 支援自定義功能名稱，並支援多語言名稱設定 —— 提升工具在多地區場景下的可讀性 |

## 協作與許可權

| 能力 | 說明 |
|------|------|
| **Agent 工作流上鎖** | 給工作流上鎖，防止協作成員誤改畫布，協作邊界更清晰 |
| **成員許可權切換** | Workspace 擁有者可在「檢視者」和「編輯者」之間切換成員許可權 |

## 使用建議

1. 團隊協作的 Workspace，主幹流程調穩後**及時上鎖**,修改走"解鎖 → 改 → 測 → 再上鎖"的流程
2. 團隊內沉澱一個"公共元件 Agent",存放調優過的常用節點 (合規話術 LLM、標準分類器等),需要時跨 Agent 複製
3. 給節點寫註釋的習慣 (見 [編排原則](../../tutorials/orchestration-debug)) 在可複製、多人協作的畫布上更加重要
