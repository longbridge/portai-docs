## 一、模型池:SOTA 模型持續接入

- 已接入多家廠商的主流與 SOTA 大語言模型，可用模型以**模型選擇器即時展示為準**
- 模型分「主流」和「SOTA」兩級，SOTA 在選擇器中有明確標識，單位消耗更高
- 部分模型受套餐或地區限制，不在選擇器中展示的即當前不可用
- 不同節點可配置不同模型 (節點級模型配置):簡單任務用主流模型、核心推理用 SOTA，是控制用量的最有效手段

## 二、賬戶與社群類 MCP 工具

五個與長橋業務深度整合的 MCP 工具，讓 Agent 能基於**使用者真實賬戶資料**提供服務：

| MCP 工具 | 能力 |
|---------|------|
| 獲取長橋社群使用者詳細資訊 | 按關鍵詞搜尋社群使用者及詳細資訊，與 App 搜尋一致 |
| 獲取詳細賬戶資訊 | 使用者當前現金、股票持倉 (成本、股數等) |
| 獲取盈虧趨勢圖 | 按幣種、時間起止、時間維度獲取盈虧走勢 |
| 獲取盈虧明細資料 | 按時間與股票程式碼獲取該標的盈虧 |
| 獲取盈虧分析彙總 | 按幣種與時間範圍獲取盈虧彙總 |

**前置條件**:涉及資產資料的呼叫會自動觸發**交易密碼校驗**(見 [1.7.8 安全校驗與本地化](security-i18n)),校驗通過才返回資料。

**合規提醒**:賬戶資料只能做**中立展示與統計分析**,不得據此生成個性化買賣建議 —— 見 [禁止投資建議](../../compliance/index)、[堅守執行專屬定位](../../compliance/index)。

## 三、行情/基本面工具時區最佳化

- 部分工具的 `start_date` / `end_date` 引數描述中增加了**美股 ET 和香港 HKT 時區說明**
- 所有返回時間欄位統一為**帶 UTC+0 時區的 ISO8601 格式**,並附介面呼叫時間的時間戳
- 效果：歷史 K 線與歷史財報查詢更精準;模型能根據介面時間和 overnight 行情時間點，判斷當前所處的交易時段

> 對搭建者的意義：行情類 Agent 的提示詞中不必再費力解釋時區，工具返回自帶明確時區資訊，減少"昨天/今天"類時間歧義錯誤。
