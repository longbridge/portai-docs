> 一個 Agent 從建立到釋出，涉及四個許可權問題：**誰能改、誰能看、誰能用、誰能複製**。本篇把這四件事一次講清。

## 許可權管理的全景

```
誰能改  → Workspace 成員角色(Owner / Editor / Viewer)+ 工作流上鎖
誰能看/用 → Agent 使用許可權三檔(僅工作空間 / 連結可用 / 釋出到廣場)
誰能複製 → 「允許 Fork」開關
執行時   → 功能繼承 Agent 所屬 Workspace,敏感資料另有內容層鑑權
```

## 誰能改：編輯許可權

### Workspace 成員角色

Agent 的編輯許可權跟隨其所屬 Workspace 的成員角色 (詳見 [1.5 Workspace 與套餐體系](plans)):

| 成員角色 | 對 Agent 的許可權 |
|---------|----------------|
| **Owner**(僅一個) | 全部許可權;唯一可執行套餐購買等商業操作 |
| **Editor**(數量隨套餐限制) | 建立、編輯、釋出 Workspace 內的 Agent |
| **Viewer**(數量隨套餐限制) | 檢視和使用，不可編輯 |

Workspace 擁有者可在成員管理頁把成員在 **Editor / Viewer** 之間切換 (見 [1.2 主要頁面介紹](pages-overview))。

### 工作流上鎖

多人協作時，給除錯穩定的 Agent 工作流**上鎖**,防止其他成員誤改畫布;修改走"解鎖 → 改 → 測 → 再上鎖"流程 (見 [畫布與協作效率](capabilities/canvas-collaboration))。

## 誰能看、誰能用：使用許可權三檔

每個 Agent 可設定使用許可權，由低到高三檔：

| 檔位 | 誰能用 | 典型用途 |
|------|--------|---------|
| **僅工作空間使用者可用**(member) | 本 Workspace 成員 | 開發除錯階段、團隊內部工具 |
| **任何獲得連結的使用者可用**(link) | 拿到分享連結的任何使用者 | 定向分享給指定的人 |
| **釋出到廣場**(public) | 所有平臺使用者可在廣場發現和使用 | 面向公眾開放 |

### 釋出的前置條件鏈

```
使用許可權設為「任何獲得連結的使用者可用」
  → 才會出現「釋出到 Agent 廣場」入口
    → 套餐為 Pro 及以上(Starter 不可釋出)
      → 通過安全掃描
        → 釋出成功
```

- 使用許可權為「僅工作空間使用者可用」時，廣場釋出入口**不展示**
- 釋出到廣場的內容稽核與安全要求見 [3.1 合規要求](../compliance/index)

### 受限模型與釋出的聯動攔截

Agent 使用了**受限模型**(受廠商條款限制、僅平臺官方可用的模型) 時，釋出許可權被自動收緊：

| Agent 當前狀態 | 平臺行為 |
|---------------|---------|
| member 態 | 釋出按鈕中「釋出到廣場」「連結分享」**置灰不可點**,只能保持 member 可見 |
| 已是 public / link 態，模型受限狀態變化後再次釋出 | **直接攔截**,彈窗二選一：改回 member 後釋出，或移除受限模型後釋出 |

選擇受限模型時平臺也會提示："使用受限模型後，該 Agent 將無法公開檢視和釋出到廣場"(具體提示文案以產品內為準)。

## 誰能複製:Fork 許可權

- 只有當釋出者開啟**「允許 Fork」開關**,其他使用者才能 Fork 你的 Agent
- Fork 的**複製範圍**:Agent 配置 + 關聯的 Skill;**不復制**知識庫和 Secret(Fork 者需自行建立知識庫、配置自己的金鑰)
- 所有套餐都可以 Fork 廣場上允許 Fork 的 Agent

> 決策建議：希望別人"用你的 Agent"→ 開放使用許可權即可;希望別人"在你的基礎上改"→ 再開允許 Fork。不想暴露提示詞和編排思路就保持 Fork 關閉。

## 執行時的許可權：使用者視角

- **功能繼承**:使用者能用到的功能由 **Agent 所屬 Workspace 的套餐**決定，與使用者自己的套餐無關 (使用者套餐隻影響用量額度)—— 詳見 [1.5 §5.5 配置時 vs 執行時](plans)
- **內容層鑑權獨立於 Agent 許可權**:涉及使用者資產資料的工具 (賬戶、持倉、盈虧),無論 Agent 許可權如何設定，執行時都會對**當前使用者本人**觸發交易密碼校驗 —— 資料只給驗證過身份的本人 (見 [安全校驗與本地化](capabilities/security-i18n))
- **用量承擔**:使用者是否為 Agent 所屬 Workspace 成員，決定了用量記在誰頭上 (開發者付費 / 使用者付費),見 [1.5 §5.4](plans)

## 使用範圍紅線

無論許可權如何配置，以下約定始終有效 (詳見 [1.6 分地區服務說明](regions)):

1. 你建立的 Agent **僅限本人使用**,不得以任何形式向他人提供商業化服務
2. 廣場中的 Agent **僅供學習交流**,其上架、展示、使用與 Fork 不構成任何商業行為或推薦

## 常見問題

| 問題 | 答案 |
|------|------|
| 為什麼我看不到「釋出到廣場」按鈕？| 先把使用許可權改為「任何獲得連結的使用者可用」;另確認套餐為 Pro 及以上 |
| 釋出/分享按鈕是灰的？| 檢查 Agent 是否使用了受限模型 (受廠商條款限制的模型),移除後即可釋出 |
| 別人 Fork 了我的 Agent，能看到我的知識庫和金鑰嗎？| 不能，Fork 只複製配置和 Skill，知識庫與 Secret 不隨 Fork 傳播 |
| 不想讓別人 Fork 但想讓別人用？| 開放使用許可權、保持「允許 Fork」關閉即可 |
| 同事誤改了我的畫布怎麼辦？| 給工作流上鎖;必要時讓 Owner 把該成員調整為 Viewer |
| Starter 使用者能用我釋出的 Agent 嗎？| 能，功能繼承你的 Workspace;對方只是消耗自己的用量額度 |
