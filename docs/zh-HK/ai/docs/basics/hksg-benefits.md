> **適用地區**:HK / SG · **性質**:限時高檔位體驗卡 (服務使用權益，非現金返還、非證券獎勵)
> 權益卡的具體資格條件、檔位、有效期以**產品內權益中心展示與對應活動條款**為準。

## 一、權益卡是什麼

權益卡是一張**限時體驗更高檔位套餐的卡**:啟用後，在有效期內你將享受**對應檔位套餐的功能權益與用量額度**(如 Pro 體驗卡 → Pro 檔位的功能與額度)。

三條核心原則：

| 原則 | 說明 |
|------|------|
| **不改變訂閱關係** | 權益卡不產生訂閱、不附加任何付費條件，也不影響你現有訂閱的續費、扣費;到期自動回落，**不會自動續費**(權益卡 ≠ 免費試用) |
| **改變你享受到的套餐權益** | 有效期內，功能許可權按「當前訂閱檔位與權益卡檔位的**較高者**」生效——Skill 數量上限、知識庫容量、第三方 MCP 等均按更高檔位判斷 |
| **用量疊加** | 付費使用者：當週剩餘額度 + 權益卡檔位的周額度;Starter 使用者：直接按權益卡檔位的額度分配 |

## 二、怎麼獲得、怎麼啟用

**獲得方式**:權益卡不公開出售、不可購買，通過以下渠道發放——

- **活動達標**:參與平臺活動並滿足條件，自動發放
- **任務獎勵**:完成任務中心的任務後發放
- **平臺定向發放**:運營向指定使用者發放 (可能通過郵件、社群、App 通知告知)

**發放 ≠ 生效**:發放後權益卡先進入**權益中心**(狀態：待使用),需要你**主動點選「立即使用」**才會啟用：

```
獲得權益卡 → 開啟用量頁,看到「你有 1 張未使用的權益卡」提示
  → 點選進入權益中心 → 點選「立即使用」→ 權益啟用,立即生效
```

- 權益中心為 App 內功能，Web 端使用者請在 App 中啟用
- **有效期按天數**計算 (如 7 / 30 / 90 天),從啟用時開始計時
- 一直不啟用的卡，超過未使用過期時間 (預設 180 天，以條款為準) 後**自動作廢**

## 三、使用規則

| # | 規則 | 說明 |
|---|------|------|
| 1 | **檔位 ≥ 當前才可用** | 權益卡檔位低於你當前訂閱檔位時無法使用 (點選「立即使用」會提示);同檔位可用，純用量疊加 |
| 2 | **一次只能生效一張** | 已有生效中的權益卡時，新卡無法使用，需等當前卡到期 (不支援排隊自動啟用) |
| 3 | **期間訂閱不受影響** | 原訂閱正常續費;期間**升級訂閱**,權益卡繼續生效、用量繼續疊加，功能按兩者較高檔位判斷 |
| 4 | **期間退訂也不影響卡** | 權益卡繼續生效直到到期;到期後回落 Starter |
| 5 | **到期即回落** | 功能回落到原套餐檔位;卡內剩餘用量**直接回收**;超限建立的 Skill 等內容不刪除，但不能再新增 |
| 6 | **不可兌現、不可轉讓** | 權益卡為服務使用權益，平臺保留活動解釋權 (以條款為準) |

## 四、在哪裡檢視

- **用量頁**:頂部展示權益卡狀態卡片——體驗檔位 + 剩餘天數 + 疊加後的當周可用額度;有未使用的卡時展示提示入口
- **套餐頁**:展示當前體驗檔位、剩餘天數與原訂閱狀態
- **權益中心**:檢視全部權益卡及其狀態 (待使用 / 使用中 / 已使用 / 已過期)

## 五、常見問題速查

| 問題 | 答案 |
|------|------|
| 領了 Pro 體驗卡，能用 Pro 的功能嗎？| **能**。有效期內功能許可權提升到 Pro 檔位 (Skill 上限、知識庫容量等按 Pro 判斷) |
| 我已經訂閱了 Pro，收到 Pro 卡有用嗎？| 有用，同檔位卡啟用後**用量疊加**(當週剩餘 + 卡的周額度),訂閱不變 |
| 我已經訂閱了 Premium，收到 Pro 卡呢？| 無法使用——權益卡檔位低於當前套餐時不生效 |
| 權益卡會讓我自動續費/產生訂閱嗎？| 不會。權益卡是純贈送權益，不產生訂閱、無任何付費條件 |
| 到期時卡里額度沒用完怎麼辦？| 直接回收，恢復原套餐額度;功能同步回落 |
| 領了卡一直不用會怎樣？| 超過未使用過期時間 (預設 180 天) 自動作廢 |
| 怎麼獲得權益卡？| 關注平臺活動與任務中心，或等待平臺定向發放;不支援購買 |

## 六、合規說明

- 權益卡屬**服務使用權益**,不構成現金返還或證券獎勵
- 各期活動條款寫明資格規則、權益內容、有效期、不可兌現/轉讓等要素
- 通過分享、社群等渠道傳播 AI 內容時，仍須遵守 [03-合規要求](../compliance/index)(AI 生成標識、免責宣告、敏感資訊脫敏)
