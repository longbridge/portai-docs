> 本篇帶你認識平臺的 8 個主要頁面：每個頁面是幹什麼的、入口在哪、常用操作有哪些。配合截圖快速建立對平臺的整體印象，細節規則見各頁面對應的專題文件。

## 一、Agent 列表

![Agent 列表](./images/1.2-1-Agent%E5%88%97%E8%A1%A8.png)

當前 Workspace 內所有 Agent 的管理入口：

- 檢視你有權訪問的全部 Agent 及其狀態 (草稿 / 已釋出)
- 搜尋、篩選定位目標 Agent
- 新建 Agent、進入編輯、複製、刪除等管理操作
- 注意:Agent 與列表內容以 **Workspace 為邊界**,切換 Workspace 後列表隨之變化 (見 [1.5](plans))

## 二、建立 Agent

![建立 Agent](./images/1.2-2-%E5%88%9B%E5%BB%BAAgent.png)

建立入口支援兩種模式，按需選擇：

| 模式 | 搭建方式 | 適合 |
|------|---------|------|
| **Agentic Chat** | 配置式：提示詞 + 掛工具 | 快速驗證想法、輕量場景 |
| **Chatflow** | 畫布編排：節點 + 連線 | 多分支路由、精確控制的生產級場景 |

- 支援 **AI 輔助建立**:描述需求，由 AI 生成初始配置 (此部分消耗由平臺承擔)
- 上手教程見 [1.3 快速上手](quick-start),模式選擇技巧見 [2.5 技巧一](../tutorials/mode-model-selection)

## 三、知識庫管理

![知識庫管理](./images/1.2-3-%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86.png)

管理供 Agent 檢索引用的知識檔案：

- 上傳、檢視、刪除知識檔案，查看向量化處理狀態
- 容量額度隨套餐變化 (如 Starter 50MB / Pro 5GB / Premium 20GB，以套餐頁即時展示為準)
- 容量超限時禁止新增，超限檔案**按上傳時間從最舊開始**標記為**停用**(不參與檢索),不自動刪除
- 知識庫能力詳解見 [1.7 平臺能力 · 知識庫](capabilities/knowledge-base)

## 四、Skill 管理

![Skill 管理](./images/1.2-4-Skill%E7%AE%A1%E7%90%86.png)

管理 Agent 可掛載的 Skill:

- 建立、編輯、刪除**自定義 Skill**(數量上限隨套餐)
- 檢視可用的**官方內建 Skill**(財報分析等，需 Pro 及以上套餐)
- Skill 數量超限時無法建立，需刪除已有或升級套餐
- Skill 體系詳解見 [1.7 平臺能力 · Skill 體系](capabilities/skill)

## 五、空間使用者管理

![空間使用者管理](./images/1.2-5-%E7%A9%BA%E9%97%B4%E7%94%A8%E6%88%B7%E7%AE%A1%E7%90%86.png)

管理當前 Workspace 的成員與許可權：

- 檢視成員列表及各自的成員角色
- 成員角色分三種：**Owner**(每個 Workspace 僅一個，擁有全部許可權)、**Editor**(可編輯資源)、**Viewer**(只讀使用);Editor 與 Viewer 的數量取決於套餐上的成員數量限制
- 僅 Owner 可執行訂閱購買/升級等商業操作
- 成員角色規則詳見 [1.5 · Workspace 成員角色](plans)

## 六、用量 (Usage)

> 💡 **入口說明**:用量、套餐、訂單三個頁面共用一個入口——點選左下角**個人頭像**開啟選單，選擇「**工作區套餐**」,在展開的二級選單中分別進入「用量」「套餐」「訂單」:

![用量/套餐/訂單入口：個人頭像選單 → 工作區套餐](./images/1.2-9-%E7%94%A8%E9%87%8F%E5%A5%97%E9%A4%90%E8%AE%A2%E5%8D%95%E5%85%A5%E5%8F%A3.png)

![用量頁](./images/1.2-6-%E7%94%A8%E9%87%8F.png)

檢視額度餘額與消耗明細：

- 有生效中的權益卡時，頂部展示**權益卡狀態卡片**(體驗檔位 + 剩餘天數 + 疊加後的當周可用額度)
- 展示當前 7 天滾動周的可用額度與月度餘額
- 消費明細展示每筆消耗的來源，以及由哪個服務主體收取 (charged by)
- 計費單元與扣量規則見 [1.5 · 用量](plans)

## 七、套餐 (Plan)

> 入口：個人頭像選單 → 工作區套餐 → 套餐 (見[第六節入口說明](#六用量usage))

![套餐頁](./images/1.2-7-%E5%A5%97%E9%A4%90.png)

檢視與管理當前 Workspace 的套餐：

- 展示當前套餐、各檔位權益對比與價格 (**以本頁即時展示為準**,幫助文件可能滯後)
- 購買 / 升級 / 降級 / 退訂入口 (**僅 Workspace Owner 可操作**)
- 升級立即生效補差價;降級次月生效;退訂到期後回落 Starter
- 定價幣種按註冊地區固定，SG 使用者頁面價格不含稅 (GST 由支付渠道額外收取),見 [1.6](regions)

## 八、訂單頁面

> 入口：個人頭像選單 → 工作區套餐 → 訂單 (見[第六節入口說明](#六用量usage))

![訂單頁](./images/1.2-8-%E8%AE%A2%E5%8D%95.png)

檢視訂閱相關的交易記錄：

- 訂單列表：每筆訂閱/續費的時間、金額、幣種與狀態
- 支付渠道資訊 (Apple IAP / Stripe)
- 訂單歸屬的服務主體與你的註冊地區一致
