> 平臺在多個地區提供服務，各地區由**獨立法律實體**運營，受當地法律法規約束。本篇說明與你直接相關的內容：你的服務主體是誰、價格與幣種如何確定、地區之間有什麼差異，以及 **Agent 的使用範圍**。

## Agent 使用範圍宣告

> **請在使用平臺前瞭解以下約定：**

1. **你建立的 Agent 僅限本人使用**,不得以任何形式向他人提供商業化服務。
2. **Agent 廣場中的 Agent 僅供學習交流使用**:廣場中 Agent 的上架、展示、使用與 Fork,**不構成任何商業行為**,也**不構成平臺或建立者的任何推薦**(包括但不限於任何投資建議、產品推薦)。
3. 平臺所有 AI 生成內容會按所在地區要求進行標註;涉及金融內容的統一約束見 [合規要求](../compliance/index)。

## 地區差異與隔離

1. **資料本地化**:資料儲存於您的所屬地區所允許的合規資料中心
2. **主體不可切換**:服務主體隨註冊地區確定，不可跨地區切換 (如 HK 使用者不能改用 SG 主體)
3. **能力可能有差異**:部分模型、工具受地區法規限制，各地區可用能力可能不同
4. **客戶端分割槽分發**:LBHK / LBSG App 分別通過對應地區的應用商店分發
5. **合規基線全球統一**:所有地區均遵守"不提供投資建議"等核心約束，搭建 Agent 時按平臺統一合規要求執行即可，無需按地區區分

| 為什麼某個模型/工具我這裡沒有？| 可能受地區法規限制，各地區可用能力存在差異 |
