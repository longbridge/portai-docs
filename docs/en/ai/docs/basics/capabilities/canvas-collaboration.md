A set of efficiency capabilities around canvas operations and team collaboration — none of them large on their own, but combined they significantly cut building costs.

## Canvas & Configuration Operations

| Capability | Description |
|------|------|
| **Multi-select batch operations** | Hold Shift and drag to select multiple nodes, then move/delete in batch |
| **Node copy & paste** | Copy a configured node directly instead of reconfiguring it |
| **Copy nodes across Agents** | A node tuned in Agent A can be pasted directly into Agent B — a great way to accumulate "node-level best practices" |
| **Custom Tool names + multilingual** | Agent Tools support custom function names with multilingual name settings — improving tool readability in multi-region scenarios |

## Collaboration & Permissions

| Capability | Description |
|------|------|
| **Agent workflow locking** | Lock a workflow to prevent collaborators from accidentally modifying the canvas, making collaboration boundaries clearer |
| **Member permission switching** | The Workspace owner can switch a member's permission between **Viewer** and **Editor** |

## Recommendations

1. In team-collaboration Workspaces, **lock the workflow promptly** once the main flow is stable; make changes via the "unlock → edit → test → lock again" process
2. Maintain a shared "common components Agent" within the team, holding tuned frequently-used nodes (compliance-scripted LLMs, standard classifiers, etc.), and copy them across Agents when needed
3. The habit of writing node comments (see [2.3 Orchestration Principles](../../tutorials/orchestration-debug)) matters even more on a copyable, multi-user canvas
