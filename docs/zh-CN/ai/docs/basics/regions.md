> 平台在多个地区提供服务，各地区由**独立法律实体**运营，受当地法律法规约束。本篇说明与你直接相关的内容：你的服务主体是谁、价格与币种如何确定、地区之间有什么差异，以及 **Agent 的使用范围**。

## Agent 使用范围声明

> **请在使用平台前了解以下约定：**

1. **你创建的 Agent 仅限本人使用**,不得以任何形式向他人提供商业化服务。
2. **Agent 广场中的 Agent 仅供学习交流使用**:广场中 Agent 的上架、展示、使用与 Fork,**不构成任何商业行为**,也**不构成平台或创建者的任何推荐**(包括但不限于任何投资建议、产品推荐)。
3. 平台所有 AI 生成内容会按所在地区要求进行标注;涉及金融内容的统一约束见 [03-合规要求](../compliance/index)。

## 地区差异与隔离

1. **数据本地化**:数据存储于您的所属地区所允许的合规数据中心
2. **主体不可切换**:服务主体随注册地区确定，不可跨地区切换 (如 HK 用户不能改用 SG 主体)
3. **能力可能有差异**:部分模型、工具受地区法规限制，各地区可用能力可能不同
4. **客户端分区分发**:LBHK / LBSG App 分别通过对应地区的应用商店分发
5. **合规基线全球统一**:所有地区均遵守"不提供投资建议"等核心约束，搭建 Agent 时按平台统一合规要求执行即可，无需按地区区分
