> **适用地区**:HK / SG · **性质**:限时高档位体验卡 (服务使用权益，非现金返还、非证券奖励)
> 权益卡的具体资格条件、档位、有效期以**产品内权益中心展示与对应活动条款**为准。

## 权益卡是什么

权益卡是一张**限时体验更高档位套餐的卡**:激活后，在有效期内你将享受**对应档位套餐的功能权益与用量额度**(如 Pro 体验卡 → Pro 档位的功能与额度)。

三条核心原则：

| 原则 | 说明 |
|------|------|
| **不改变订阅关系** | 权益卡不产生订阅、不附加任何付费条件，也不影响你现有订阅的续费、扣费;到期自动回落，**不会自动续费**(权益卡 ≠ 免费试用) |
| **改变你享受到的套餐权益** | 有效期内，功能权限按「当前订阅档位与权益卡档位的**较高者**」生效——Skill 数量上限、知识库容量、第三方 MCP 等均按更高档位判断 |
| **用量叠加** | 付费用户：当周剩余额度 + 权益卡档位的周额度;Starter 用户：直接按权益卡档位的额度分配 |

## 怎么获得、怎么激活

**获得方式**:权益卡不公开出售、不可购买，通过以下渠道发放——

- **活动达标**:参与平台活动并满足条件，自动发放
- **任务奖励**:完成任务中心的任务后发放
- **平台定向发放**:运营向指定用户发放 (可能通过邮件、社群、App 通知告知)

**发放 ≠ 生效**:发放后权益卡先进入**权益中心**(状态：待使用),需要你**主动点击「立即使用」**才会激活：

```
获得权益卡 → 打开用量页,看到「你有 1 张未使用的权益卡」提示
  → 点击进入权益中心 → 点击「立即使用」→ 权益激活,立即生效
```

- 权益中心为 App 内功能，Web 端用户请在 App 中激活
- **有效期按天数**计算 (如 7 / 30 / 90 天),从激活时开始计时
- 一直不激活的卡，超过未使用过期时间 (默认 180 天，以条款为准) 后**自动作废**

## 使用规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **档位 ≥ 当前才可用** | 权益卡档位低于你当前订阅档位时无法使用 (点击「立即使用」会提示);同档位可用，纯用量叠加 |
| 2 | **一次只能生效一张** | 已有生效中的权益卡时，新卡无法使用，需等当前卡到期 (不支持排队自动激活) |
| 3 | **期间订阅不受影响** | 原订阅正常续费;期间**升级订阅**,权益卡继续生效、用量继续叠加，功能按两者较高档位判断 |
| 4 | **期间退订也不影响卡** | 权益卡继续生效直到到期;到期后回落 Starter |
| 5 | **到期即回落** | 功能回落到原套餐档位;卡内剩余用量**直接回收**;超限创建的 Skill 等内容不删除，但不能再新增 |
| 6 | **不可兑现、不可转让** | 权益卡为服务使用权益，平台保留活动解释权 (以条款为准) |

## 在哪里查看

- **用量页**:顶部展示权益卡状态卡片——体验档位 + 剩余天数 + 叠加后的当周可用额度;有未使用的卡时展示提示入口
- **套餐页**:展示当前体验档位、剩余天数与原订阅状态
- **权益中心**:查看全部权益卡及其状态 (待使用 / 使用中 / 已使用 / 已过期)

## 常见问题速查

| 问题 | 答案 |
|------|------|
| 领了 Pro 体验卡，能用 Pro 的功能吗？| **能**。有效期内功能权限提升到 Pro 档位 (Skill 上限、知识库容量等按 Pro 判断) |
| 我已经订阅了 Pro，收到 Pro 卡有用吗？| 有用，同档位卡激活后**用量叠加**(当周剩余 + 卡的周额度),订阅不变 |
| 我已经订阅了 Premium，收到 Pro 卡呢？| 无法使用——权益卡档位低于当前套餐时不生效 |
| 权益卡会让我自动续费/产生订阅吗？| 不会。权益卡是纯赠送权益，不产生订阅、无任何付费条件 |
| 到期时卡里额度没用完怎么办？| 直接回收，恢复原套餐额度;功能同步回落 |
| 领了卡一直不用会怎样？| 超过未使用过期时间 (默认 180 天) 自动作废 |
| 怎么获得权益卡？| 关注平台活动与任务中心，或等待平台定向发放;不支持购买 |
