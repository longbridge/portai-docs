> 官方 Chatbot 体系与 Agent Platform 共同构成长桥的 AI 产品,**用户的用量额度在两者间通用**。本篇介绍 Chatbot 侧的能力,**Agent 搭建者了解即可**:你的 Agent 发布后,用户在这些能力的加持下与它交互。

## 呈现与交互

| 能力 | 说明 |
|------|------|
| **会话图表** | 结构化投资数据在对话中以专业图表直观呈现,趋势/对比一目了然;图表可交互,用户可围绕同组数据继续追问 |
| **股票行情 / 清单 Widget** | 对话中的行情卡片与股票清单组件;Stock Card 支持分享截屏 |
| **思考链与引用** | 思考链分阶段展示、支持多形态切换;引用以可点击的网站链接形式展示 |
| **回答重试分支** | 重试后按分支切换查看不同次运行的回答,方便对比 |
| **语音输入** | 像聊天一样开口提问,复杂长句一口气讲清 |

## 记忆与个性化

| 能力 | 说明 |
|------|------|
| **长期记忆** | 触发长期记忆时显式提示已记住的内容,支持快捷入口管理全部记忆 |
| **历史聊天记录检索** | 对话自动落库并定期生成摘要;用户问"上次/之前/以前给你的格式"时,AI 自动检索历史对话完成回忆 —— **以用户为维度,跨 Agent 生效** |
| **用户标签** | 用户可主动维护个性化要求,AI 对话前检索标签生成个性化回复 |
| 个性化问题推荐 | 基于热门股票池的真实技术面/新闻/社区热议生成推荐问题,热度越高更新越快 |
| 推荐问句与追问 | 推荐问句支持「换一换」;追问基于近几轮问答动态生成 |

> 说明:「个性化问题推荐」与「推荐问句与追问」**仅在官方 Chatbot 中生效,与你搭建的 Agent 无关**——你的 Agent 展示给用户的引导问题,由设置项中的「Agent 预设问题」自行配置(见 [1.10 设置项](../chatflow-agenticchat-settings))。

## 对搭建者的启示

1. **输出结构化数据有红利**:核心数据以结构化形式输出,C 端会自动以图表/Widget 呈现,体验远好于纯文本(见 [2.2 结构化输出](../../tutorials/variables-dataflow))
2. **回答风格:结论前置、去废话** —— 你的 Agent 提示词同样适用这套原则(见 [2.1](../../tutorials/prompt-writing))
3. **个性化由平台层完成**:用户标签、历史记忆在平台层生效,Agent 无需自建用户画像 —— 也**不应**自建,见 [数据使用与隐私限制](../../compliance/index)
