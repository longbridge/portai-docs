## 是什么

把你的本地文档上传到平台，经解析、分块、向量化后供 Agent 检索使用 —— 让 Agent 基于**你的私有知识**作答，而不是只靠模型的通用知识。典型场景：产品 FAQ 客服、内部制度问答、研究资料辅助分析。

![知识库首页：空态时的「创建知识库」入口](./images/01-1-%E7%9F%A5%E8%AF%86%E5%BA%93%E9%A6%96%E9%A1%B5.png)

## 创建流程 (四步)

1. **创建知识库**:填写名称、描述，选择检索设置。支持三种检索方式：
   - **混合检索**(推荐默认):向量 + 全文结合
   - **向量检索**:语义相似度匹配，适合口语化提问
   - **全文检索**:关键词精确匹配，适合术语、代码、编号类查询
   - 也可点击「创建空白知识库」先建库、后续再补文件

   ![创建知识库：名称、描述与检索设置 (混合检索为推荐默认)](./images/01-2-%E5%88%9B%E5%BB%BA%E7%9F%A5%E8%AF%86%E5%BA%93.png)

2. **上传文件**:拖拽或选择文件，每次最多 5 个、单个不超过 10MB;支持 DOCX、PPTX、HTML、PDF、MD、CSV、XLSX、VTT、JPG、PNG、TXT

   ![上传文件：拖拽或选择，支持格式与大小限制说明](./images/01-3-%E4%B8%8A%E4%BC%A0%E6%96%87%E4%BB%B6.png)

   ![已上传文件列表：大文档可拆分为多个文件分批上传 (示例为一本书按页码区间拆成 4 个 PDF)](./images/01-4-%E6%96%87%E4%BB%B6%E5%B7%B2%E4%B8%8A%E4%BC%A0.png)

3. **文本设置**:按文件类型自定义分段长度 (默认 1024 字符)、文本预处理规则 (替换连续空格换行/删除 URL 与邮箱)、**分段语义增强**(启用图片内容理解 vlm),并点击「预览块」**预览分块效果** —— 分块质量直接决定检索质量，值得在这一步多花时间

   ![文本设置：分块长度、预处理规则、语义增强与分块预览](./images/01-5-%E6%96%87%E6%9C%AC%E8%AE%BE%E7%BD%AE.png)

4. **处理并完成**:查看嵌入处理进度 (每个文件独立显示步骤与百分比),下方汇总本次的分段模式、分块长度、预处理规则与检索设置;可直接「转到文档列表页」,处理在后台继续

   ![处理并完成：嵌入处理进度与配置汇总](./images/01-6-%E5%A4%84%E7%90%86%E5%B9%B6%E5%AE%8C%E6%88%90.png)

## 日常管理

- **知识库列表**:知识库 tab 以卡片展示全部知识库 (检索方式、文档数、更新时间),顶部展示**容量使用进度**;卡片右上角「…」进入管理操作

  ![知识库列表页：容量进度条与知识库卡片](./images/01-7-%E7%9F%A5%E8%AF%86%E5%BA%93%E5%88%97%E8%A1%A8.png)

- **文档列表**(知识库详情页):按处理状态筛选、按名称搜索;展示字符数、**召回次数**(哪些文档真正被用到)、上传时间与状态 (如「索引中」);每个文档支持启用/禁用开关与更多操作，右上角可继续「添加文件」

  ![知识库详情页：文档列表与状态、启用开关](./images/01-8-%E6%96%87%E6%A1%A3%E5%88%97%E8%A1%A8.png)

- **知识库设置**:修改知识库的名称、描述与**检索设置**(混合/向量/全文可随时切换，混合检索支持高级设置调整权重)

  ![知识库设置页：名称、描述与检索设置修改](./images/01-9-%E7%9F%A5%E8%AF%86%E5%BA%93%E8%AE%BE%E7%BD%AE.png)

- **分段编辑**:点进单个文档可查看最终给到大模型的分块内容，支持对具体段落再编辑、编辑关键词;「添加分段」可在文档首段插入自定义内容并配关键词
- **召回测试**:见下节

## 召回测试

入口在知识库详情页右上角 (添加文件按钮左侧)。左侧输入**源文本**(上限 200 字符)、确认检索方式，点击「测试」:

![召回测试：源文本输入、检索方式与测试按钮](./images/01-10-%E5%8F%AC%E5%9B%9E%E6%B5%8B%E8%AF%95.png)

右侧展示命中的**召回块**:每块显示分块序号、字符数与**相关性分数**(如 0.67),用于判断检索质量：

![召回测试结果：命中 3 个召回块，展示分块信息与分数](./images/01-11-%E5%8F%AC%E5%9B%9E%E6%B5%8B%E8%AF%95%E7%BB%93%E6%9E%9C.png)

- 召回块底部标注**来源文件**,可确认内容出自哪份文档
- 左下「记录」列表保留历史测试 (检索方法、query、时间),方便换检索方式对同一 query **对比效果**
- 建议用"用户真实会问的问题"做 query，而不是文档里的原句——原句召回分数天然偏高，测不出真实效果

![召回测试记录：历史 query 列表，召回块底部标注来源文件](./images/01-12-%E5%8F%AC%E5%9B%9E%E6%B5%8B%E8%AF%95%E8%AE%B0%E5%BD%95.png)

## 在流程中使用

两个挂载位置，均由 Agent 在**必要时自动检索**所选知识库：

**① Agentic Chat**:Agent 配置页的「知识库」区，点「+ 添加知识库」挂载 (与 Skills 区相邻，参考 [1.7.2 Skill 体系](skill) 的配置页截图)。

**② Chatflow / Workflow 的 Agent 节点**:节点编辑面板中打开「知识库」开关，点 `+` 选择要挂载的知识库：

![Agent 节点：知识库开关开启后出现选择入口](./images/01-13-Agent%E8%8A%82%E7%82%B9%E7%9F%A5%E8%AF%86%E5%BA%93%E5%BC%80%E5%85%B3.png)

选好后以标签形式展示 (可挂多个):

![Agent 节点：已挂载「投资书籍知识库」](./images/01-14-Agent%E8%8A%82%E7%82%B9%E7%9F%A5%E8%AF%86%E5%BA%93%E5%B7%B2%E9%80%89.png)

### 写好描述，方便 Agent 召回

Agent 依靠知识库的**名称与描述**判断"什么问题需要查这个库"——描述要写清**覆盖的内容范围**(如"投资知识库，目前包括期权的相关数据"),Agent 遇到期权类问题时才知道该来检索;描述含糊或缺失会导致该召回时不召回：

![知识库设置：描述写清内容范围，方便 Agent 判断何时召回](./images/01-15-%E9%85%8D%E7%BD%AE%E7%9F%A5%E8%AF%86%E5%BA%93%E6%8F%8F%E8%BF%B0.png)

### 运行时的召回效果

配置完成后，用户提问命中知识库覆盖范围时，Agent 会自动检索：**推理过程**中展示「知识库检索」步骤 (含检索词),回答正文中以 `Document +N` 标记标注引用来源：

![对话中提问期权问题，推理过程显示知识库检索步骤，回答带 Document 引用标记](./images/01-16-%E5%AF%B9%E8%AF%9D%E4%B8%AD%E7%9F%A5%E8%AF%86%E5%BA%93%E5%8F%AC%E5%9B%9E.png)

点开「知识库检索」步骤可查看**请求/响应详情**——请求包含目标知识库与检索词，响应展示每个命中分块的内容、相关性分数 (score) 与排名 (rank),可用于排查召回质量：

![知识库检索详情：请求 (dataset_uids/query) 与响应 (分块 content/score/rank)](./images/01-17-%E7%9F%A5%E8%AF%86%E5%BA%93%E6%A3%80%E7%B4%A2%E8%AF%A6%E6%83%85.png)

提示词中应明确"仅基于检索到的内容作答，检索不到时如实说明",避免模型编造。

## 注意事项

1. **容量随套餐**:Starter 50MB / Pro 5GB / Premium 20GB;超限后禁止新增，超限文件按上传时间从最旧开始标记为禁用 (不参与检索),删文件或升级可恢复 —— 详见 [1.5 Workspace 与套餐体系](../plans)
2. **Embedding 计费**:文档向量化按 token 消耗用量额度
3. **合规**:面向客户的知识库内容须来自合规来源，不得包含 PII 和未公开重大信息，见 [数据使用与隐私限制](../../compliance/index)
4. 上线前用召回测试跑一遍典型问题，确认检索质量再发布
