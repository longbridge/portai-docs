## 模型池:SOTA 模型持续接入

- 已接入多家厂商的主流与 SOTA 大语言模型，可用模型以**模型选择器实时展示为准**
- 模型分「主流」和「SOTA」两级，SOTA 在选择器中有明确标识，单位消耗更高
- 部分模型受套餐或地区限制，不在选择器中展示的即当前不可用
- 不同节点可配置不同模型 (节点级模型配置):简单任务用主流模型、核心推理用 SOTA，是控制用量的最有效手段

## 账户与社区类 MCP 工具

五个与长桥业务深度集成的 MCP 工具，让 Agent 能基于**用户真实账户数据**提供服务：

| MCP 工具 | 能力 |
|---------|------|
| 获取长桥社区用户详细信息 | 按关键词搜索社区用户及详细信息，与 App 搜索一致 |
| 获取详细账户信息 | 用户当前现金、股票持仓 (成本、股数等) |
| 获取盈亏趋势图 | 按币种、时间起止、时间维度获取盈亏走势 |
| 获取盈亏明细数据 | 按时间与股票代码获取该标的盈亏 |
| 获取盈亏分析汇总 | 按币种与时间范围获取盈亏汇总 |

**前置条件**:涉及资产数据的调用会自动触发**交易密码校验**(见 [1.7.8 安全校验与本地化](security-i18n)),校验通过才返回数据。

**合规提醒**:账户数据只能做**中立展示与统计分析**,不得据此生成个性化买卖建议 —— 见 [禁止投资建议](../../compliance/index)、[坚守执行专属定位](../../compliance/index)。

## 行情/基本面工具时区优化

- 部分工具的 `start_date` / `end_date` 参数描述中增加了**美股 ET 和香港 HKT 时区说明**
- 所有返回时间字段统一为**带 UTC+0 时区的 ISO8601 格式**,并附接口调用时间的时间戳
- 效果：历史 K 线与历史财报查询更精准;模型能根据接口时间和 overnight 行情时间点，判断当前所处的交易时段

> 对搭建者的意义：行情类 Agent 的提示词中不必再费力解释时区，工具返回自带明确时区信息，减少"昨天/今天"类时间歧义错误。
