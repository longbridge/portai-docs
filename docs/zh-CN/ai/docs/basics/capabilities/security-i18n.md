## 交易密码校验

**是什么**:当流程中包含**涉及用户资产数据获取**的工具 (账户信息、持仓、盈亏等) 时，运行 Workflow 或与该类 Chatflow 对话会自动弹出**交易密码校验弹窗**,校验通过后才能获取资产数据。

**对搭建者意味着什么**:

- 鉴权由平台统一处理，**无需额外开发**,Web 端与 App 端均已适配
- Chatflow 中涉及用户鉴权的工具**所有套餐均可使用**,鉴权与套餐等级无关，用户运行时按需完成授权即可
- Workflow 为自动化运行场景，无法在运行时完成交互式鉴权，因此 Workflow 编辑器中**不展示需要用户鉴权的工具**

**合规意义**:资产数据属于敏感数据，交易密码校验保证了"数据只给验证过身份的本人"——这也是使用账户/持仓/盈亏类 MCP 工具 (见 [1.7.10 模型与工具生态](model-tool-ecosystem)) 的前置条件。

## Answer 输出简繁自动转换

**是什么**:在 Chatflow 画布后台开启**中文简/繁转换**后，Answer 节点输出的内容会根据**用户的系统语言**自动进行简体 ↔ 繁体转换。

**为什么重要**:平台服务香港、新加坡等多地区用户 (见 [1.6 分地区服务说明](../regions)),开启后无需为简繁维护两套提示词或两个 Agent，一份流程自动适配。

**使用建议**:面向 HK 用户的 Chatflow 建议默认开启;开启后用简繁两种系统语言各测一遍输出效果。
