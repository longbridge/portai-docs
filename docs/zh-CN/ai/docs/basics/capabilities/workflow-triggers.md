> ⚠️ Workflow 使用门槛较高，**暂未对普通用户开放**,本篇供提前了解，开放时间以产品公告为准。

## 是什么

为 Workflow 配置自动触发方式，无需手动运行 —— 让 Agent 按**定时器**或 **Webhook** 自动执行，实现无人值守的自动化任务 (晨间简报、定期巡检、外部系统联动等)。

## 两种触发方式

### 定时触发

- 填写 **Cron 表达式**并选择时区
- 面板**实时预览接下来 5 次执行时间**,写完表达式立刻能确认对不对

### Webhook 触发

- 系统生成 Webhook URL，复制后提供给外部系统即可
- 可配置接收的请求参数 (**Headers、Query、Body**) 及响应内容
- 外部系统调用 URL 即触发 Workflow 运行

## 使用步骤

1. 打开 Workflow 编辑器，点击 Start 节点，点击顶部 **Trigger Mode** 开启触发器模式
2. 在面板中开启「定时触发」或「Webhook 触发」并完成配置
3. **调试**:点击运行按钮，下拉菜单中选择对应 trigger 进入调试模式，发布前验证触发效果
4. 调试确认后**发布** Workflow，触发器即刻生效自动调度

## 注意事项

1. 开启触发模式后，**Start 节点的输入变量会切换为触发器定义的字段**,关闭后恢复原有变量
2. 定时触发和 Webhook 触发**可同时启用**,互不影响
3. Webhook 为**异步执行**:外部请求会立即收到配置的响应，Workflow 在后台运行 —— 外部系统不要依赖响应体获取运行结果
4. **试运行链接与发布后的生产链接不同**,对接外部系统时务必使用生产链接
5. 自动触发的运行同样消耗 Workspace 用量额度，定时任务上线前先估算频率 × 单次消耗，避免额度被静默耗尽 (见 [Workspace 与套餐体系](../plans))
