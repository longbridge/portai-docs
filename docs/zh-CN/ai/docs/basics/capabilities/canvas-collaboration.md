围绕画布操作和团队协作的一组效率能力，单项都不大，组合起来显著降低搭建成本。

## 画布与配置操作

| 能力 | 说明 |
|------|------|
| **多选节点批量操作** | 按住 Shift 后鼠标框选，批量移动/删除 |
| **节点复制粘贴** | 配好的节点直接复制，不用重新配置 |
| **跨 Agent 复制节点** | 在 A Agent 里调好的节点可直接粘贴到 B Agent —— 沉淀"节点级最佳实践"的利器 |
| **Tool 自定义名称 + 多语言** | Agent Tool 支持自定义功能名称，并支持多语言名称设置 —— 提升工具在多地区场景下的可读性 |

## 协作与权限

| 能力 | 说明 |
|------|------|
| **Agent 工作流上锁** | 给工作流上锁，防止协作成员误改画布，协作边界更清晰 |
| **成员权限切换** | Workspace 拥有者可在「查看者」和「编辑者」之间切换成员权限 |

## 使用建议

1. 团队协作的 Workspace，主干流程调稳后**及时上锁**,修改走"解锁 → 改 → 测 → 再上锁"的流程
2. 团队内沉淀一个"公共组件 Agent",存放调优过的常用节点 (合规话术 LLM、标准分类器等),需要时跨 Agent 复制
3. 给节点写注释的习惯 (见 [编排原则](../../tutorials/orchestration-debug)) 在可复制、多人协作的画布上更加重要
