## 功能说明

IF Else 节点提供强大的条件判断能力：

- **条件分支**: 支持 IF、ELIF、ELSE 多重条件判断
- **运算符丰富**: 支持字符串、比较、空值等多种运算符
- **逻辑组合**: 支持 AND、OR 逻辑关系组合
- **流程控制**: 根据条件控制工作流执行路径

## 节点编辑区域

![条件分支编辑面板:IF/ELIF 条件配置 (引用变量 + 运算符 + 比较值，AND/OR 切换)、+ELIF 添加分支、ELSE 兜底说明，以及「下一步」中各分支的跳转目标节点](./images/07-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. IF 条件分支
- **子条件**: 支持选择变量，点击后弹出选择变量窗口
- **比较值**: 支持输入值
- **运算符**: 变量和比较值之间的运算符包括：
  - **包含**: 检查变量是否包含指定值
  - **不包含**: 检查变量是否不包含指定值
  - **开始是**: 检查变量是否以指定值开始
  - **结束是**: 检查变量是否以指定值结束
  - **是**: 检查变量是否等于指定值
  - **不是**: 检查变量是否不等于指定值
  - **为空**: 检查变量是否为空
  - **不为空**: 检查变量是否不为空
- **逻辑关系**: 子条件之间关系，支持 And 或者 OR

### 2. ELIF（Else IF 条件分支）
- **配置方式**: 同 IF 条件分支，可以添加和移除
- **条件判断**: 支持多个 ELIF 条件
- **优先级**: 按顺序进行条件判断

### 3. ELSE
- **默认分支**: 当所有条件都不满足时执行
- **必需分支**: 建议总是包含 ELSE 分支

### 4. 下一步配置
- **分支数量**: 有多少分支，则自动展示分支的下一步
- **分支连接**: 每个分支可以连接不同的下一个节点

## 常见问题

### Q: 如何添加多个条件？
A: 可以使用 ELIF 添加多个条件，或者使用 AND/OR 组合多个子条件。

### Q: 运算符如何选择？
A: 根据数据类型和比较需求选择合适的运算符。

### Q: 可以有多少个分支？
A: 理论上没有限制，但建议保持合理的分支数量。

### Q: 如何确保条件覆盖完整？
A: 使用 ELSE 分支作为默认情况，确保所有情况都有对应的处理。

### Q: 条件判断的性能如何？
A: 条件判断性能很好，但建议避免过于复杂的条件逻辑。
