## 节点概述

**节点英文名**: Parameter Extractor  
**节点中文名称**: 参数提取器  
**支持场景**: Chatflow Agent（支持）, Workflow Agent（支持）  

## 功能说明

参数提取器节点利用大模型从自然语言文本中**提取结构化参数**：配置要提取的参数定义（或直接从工具导入入参定义），模型从输入变量中识别并抽取对应的值，输出供后续节点使用——最典型的场景是把用户的自然语言请求转换为下游 Tool 节点所需的调用参数。

## 节点编辑区域

![参数提取器编辑面板:模型、输入变量、提取参数(可从工具导入)、指令、失败时重试与异常处理](./images/13-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. 模型配置
- **模型选择**: 必填,同LLM节点的模型配置方式——参数提取由该模型完成

### 2. 输入变量
- **变量选择**: 输入 `/` 插入变量,选择要从中提取参数的来源文本(如 `开始/sys.query` 或上游节点输出)

### 3. 提取参数
- **添加参数**: 点击 `+` 手动定义要提取的参数(参数名、类型、说明、是否必填)
- **从工具中导入**: 一键导入某个工具的入参定义作为提取目标——**典型用法**:先用参数提取器从用户自然语言中提取出工具需要的参数,再传给下游 Tool 节点调用

### 4. 指令
- **附加指令**: 可编写提取的补充指令(如格式要求、歧义处理规则),编辑器同LLM节点的Prompt输入,支持 `/` 插入变量

### 5. 容错配置
- **失败时重试**: 开关,提取失败时自动重试
- **异常处理**: 下拉选择异常处理策略(默认「无」)

### 6. 下一步配置
- 支持添加下一个节点

## 使用场景

### 1. 自然语言转工具参数（最典型）
- 用户说「帮我看下特斯拉最近两周的新闻」→ 提取 `symbol="TSLA.US"`、`days=14` → 传给下游 Tool 节点调用
- 配合「从工具中导入」：直接以工具入参定义为提取目标，无需手工建参数

### 2. 结构化信息收集
- 从用户的自然语言或多轮对话文本中提取姓名、日期、金额等结构化字段
- 提取结果供 IF Else 分支判断、Code 节点加工或 Answer 节点引用

### 3. 歧义与默认值处理
- 在「指令」中约定歧义处理规则（如「未指明市场时默认美股」「日期相对表述换算为绝对日期」）

## 常见问题

### Q: 提取不准确怎么办？
A: 把参数的「说明」写得更具体（含格式与示例）、在指令中补充规则，或更换能力更强的模型（参考 2.5 技巧二）。

### Q: 如何与工具节点配合？
A: 用「从工具中导入」一键导入工具入参定义，提取结果的字段即可直接对接下游 Tool 节点。

### Q: 提取失败或字段缺失怎么办？
A: 开启「失败时重试」，并按流程重要性配置「异常处理」策略；必填参数建议在下游增加兜底判断。

## 注意事项

1. **模型必填**: 提取由所选模型完成，提取质量取决于模型能力
2. **参数说明质量**: 参数名、类型、说明写得越清楚，提取越准确
3. **容错配置**: 重要流程务必配置失败重试与异常处理
4. **来源文本**: 输入变量应指向包含目标信息的文本（如 sys.query 或上游输出）
