## 节点概述

**节点英文名**: Loop  
**节点中文名称**: 循环  
**支持场景**: Chatflow Agent（支持）, Workflow Agent（支持）  

## 功能说明

Loop节点按设定的循环次数或条件反复执行同一段逻辑，常用于批量处理或多次迭代。它提供了强大的循环控制能力，支持条件循环和计数循环两种模式。

## 循环类型

### 1. 条件循环
基于条件判断的循环：

```
WHILE 条件满足:
    执行循环体
    更新循环变量
    检查中止条件
```

### 2. 计数循环
基于循环次数的循环：

```
FOR i = 1 TO 最大次数:
    执行循环体
    更新循环变量
    检查中止条件
```

### 3. 混合循环
同时使用条件和计数：

```
FOR i = 1 TO 最大次数:
    IF 条件满足:
        执行循环体
        更新循环变量
        检查中止条件
    ELSE:
        提前退出
```

## 常见问题

### Q: 如何设置循环终止条件？
A: 可以设置多个条件，使用AND/OR逻辑关系，当条件满足时循环终止。

### Q: 最大循环次数如何确定？
A: 根据业务需求和性能考虑设置，范围是1-100次。

### Q: 循环变量如何管理？
A: 循环变量在循环过程中更新，循环结束时作为输出变量。

### Q: 如何避免无限循环？
A: 设置合理的终止条件和最大循环次数，确保循环能够正常结束。

### Q: 循环性能如何优化？
A: 优化循环体逻辑，减少不必要的操作，合理设置循环次数。
