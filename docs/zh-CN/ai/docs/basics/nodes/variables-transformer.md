## 节点概述

**节点英文名**: Variables Transformer  
**节点中文名称**: 模版转换  
**支持场景**: Chatflow Agent（支持）, Workflow Agent（支持）  

## 功能说明

Variables Transformer节点对工作流中已有的变量进行格式化、类型转换或合并拆分，以满足后续节点的数据需求。它提供了强大的数据转换能力，支持使用Jinja2模板语言进行复杂的变量处理。

## Jinja2模板语言

### 1. 基本语法
- **变量输出**: `{{ variable_name }}`
- **控制结构**: `{% if condition %}...{% endif %}`
- **循环结构**: `{% for item in list %}...{% endfor %}`
- **注释**: `{# 这是注释 #}`

### 2. 过滤器
- **字符串过滤器**: `upper`, `lower`, `title`, `capitalize`
- **数字过滤器**: `round`, `int`, `float`, `abs`
- **列表过滤器**: `join`, `length`, `first`, `last`, `list`

### 3. 内置函数
- **range**: 生成数字序列
- **dict**: 创建字典
