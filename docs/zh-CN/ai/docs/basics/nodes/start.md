## 节点概述

**节点英文名**: Start  
**节点中文名称**: 开始  
**支持场景**: Chatflow Agent, Workflow Agent  

## 功能说明

Start节点是流程的起始节点，用于初始化流程上下文或进行初始数据准备。它是每个工作流的入口点，负责设置流程的初始状态和变量。

## 节点展示内容


### 1. 基本信息展示
- **图标**: 节点专用图标
- **名称**: 节点名称（默认为"开始"）
- **自定义字段**: 用户添加的自定义变量
- **注释**: 用户添加的说明文字

### 2. 操作按钮
- **更多按钮**: 点击后展示右键菜单内容

### 2. 输入字段配置

#### a. 自定义变量
- 支持添加自定义变量：点击「输入字段」标题右侧的 **+ 按钮**（位置见下图红色箭头处）
- 自定义变量可以为空
- 变量展示内容包括：
  - 变量的符号
  - 变量名
  - 变量说明
  - 变量类型图标
  - 必填/非必填图标

![输入字段的添加按钮位置(+ 号),下方为系统变量列表](./images/01-3-%E8%BE%93%E5%85%A5%E5%AD%97%E6%AE%B5%E6%B7%BB%E5%8A%A0%E6%8C%89%E9%92%AE.png)

> 💡 **两种应用类型对「输入字段」的依赖完全不同:**
>
> - **Chatflow:一般情况下不需要使用**。用户输入通过系统变量 `sys.query` 传入即可。后续 Agent 平台将开放**正式输入时输入框的结构化输入能力**——届时用户可以在对话输入框中按字段填写内容，你在这里定义的输入字段才会真正产生作用。现阶段可以直接跳过本配置。
> - **Workflow:强依赖自定义输入字段**。Workflow 没有聊天输入框,Start 节点的自定义字段就是整个流程的**输入参数**(由 API 调用方或触发器传入),必须在这里定义清楚字段名、类型和是否必填,下游节点才能引用。开启触发器模式后,输入变量会切换为触发器定义的字段(见 [Workflow 触发器](../capabilities/workflow-triggers))。

#### b. 默认变量（系统变量）
- `sys.query`: String类型（仅Chatflow Agent存在且为默认值），这个是最关键的输入变量。后面要用到。
- `sys.language`: String类型（仅Chatflow Agent存在且为默认值）
- `sys.user_id`: String（系统变量，不可移除）
- `sys.app_id`: String（系统变量，不可移除）
- `sys.workflow_id`: String（系统变量，不可移除）
- `sys.workflow_run_id`: String（系统变量，不可移除）
  作为用户不太需要知道其他系统变量是啥含义，这里不做赘述

### 3. 安全与合规开关

![安全与合规开关配置区,含输出变量与下一步区域](./images/01-4-%E5%AE%89%E5%85%A8%E5%90%88%E8%A7%84%E5%BC%80%E5%85%B3.png)

Start 节点提供四个安全与合规相关的开关,默认均为关闭状态:

#### a. 隐藏个人身份信息
- 开启后,系统将自动识别用户输入中的**个人身份信息(PII)**,并以星号(`*`)替换
- 被隐藏的信息在后续会话中将**不再展示**
- 开启后,输出变量区会提供 `pii_flagged`(Boolean 类型)——个人身份信息检查标记,供下游节点判断本次输入是否命中了 PII 识别

#### b. 屏蔽不良内容
- 开启后,系统将自动识别用户输入中涉及**仇恨、骚扰、自残、暴力、色情、未成年人相关、违法及其他高风险内容类型**
- 一旦检测到相关内容,系统将**阻断响应**,不再继续处理或返回结果

#### c. 屏蔽不良的金融领域内容
- 开启后,系统将依据适用的法律法规、监管要求及平台合规与风险控制规则,对用户输入内容进行自动识别与审核
- 如检测到涉及**非法交易建议**的内容,包括但不限于:
  - 洗钱(如隐匿资金来源、分层交易、拆分交易)
  - 逃税、证券欺诈、内幕交易、市场操纵
  - 恐怖融资或规避制裁
  - 使用被盗或伪造的身份、账户或支付工具进行交易
  - 其他明显违法或被禁止的交易行为及金融犯罪
- 系统将**阻断相关响应并终止后续处理**

#### d. 强制交易密码校验
- **内部用途**开关,不推荐普通用户使用

### 4. 输出变量

- `pii_flagged`: Boolean 类型,个人身份信息检查标记(配合「隐藏个人身份信息」开关使用,见上文)

## 节点数量控制

- **限制**: 只能有一个Start节点
- **用途**: 作为工作流的唯一入口点

## 测试运行

- **支持状态**: 支持测试运行
- **更改节点**: 不支持
- **复制功能**: 不支持复制、剪贴、删除


## 使用建议

1. **变量规划**: 在Start节点中预先定义好整个流程需要的变量
2. **命名规范**: 为自定义变量使用清晰的命名规范
3. **必填设置**: 合理设置变量的必填/非必填属性
4. **流程设计**: 确保Start节点连接到合适的下一个节点

## 注意事项

- Start节点是工作流的必需节点，每个工作流必须有且仅有一个
- 系统变量不可删除，确保流程正常运行
- 自定义变量可以根据业务需求灵活配置
- 建议在Start节点中完成所有必要的初始化工作
