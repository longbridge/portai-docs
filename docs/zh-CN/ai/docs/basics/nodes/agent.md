## 快速参考

> Agent 节点**没有策略选择**,默认均为 **Function Calling 模式**(模型通过函数调用来使用工具，循环执行直到任务完成)。

## 功能说明

**Agent 节点是平台最核心的节点之一**。它的本质是一个 **LLM 的循环**:LLM 在循环中自主决定下一步动作，直到任务完成，可以完成各种复杂度较高的功能，包括：

- **规划**: 拆解任务，决定执行步骤
- **回答问题**: 生成回复内容
- **调用工具**: 使用挂载的工具获取信息或执行操作
- **使用 Skill**: 调用挂载的 Skill 完成专项任务
- **开启沙盒**: 在沙盒环境中执行代码
- **运行脚本**: 执行脚本处理数据或逻辑
- **运行 HITL**: 人机协作 (Human-in-the-Loop),在关键步骤引入人工确认

此外还支持：
- **工作流集成**: 调用已有 Agent Tool，支持多步对话和业务处理

#### c. 工具搜索

![工具搜索开关](./images/05-4-%E5%B7%A5%E5%85%B7%E6%90%9C%E7%B4%A2.png)

- 开启「工具搜索」后，**未显式勾选的套餐内工具**会通过 `tool_search` 元工具**按需检索并加载到上下文末尾**
- 效果：**显著降低提示词体量，并提升工具选择准确度**
- 适合工具较多的场景——不必把所有工具都塞进上下文，让模型按需取用

### 6. 功能开关

Agent 节点提供一组能力开关，按需开启：

#### a. 用户标签

- 开启后，LLM 会在**需要个性化回答的场景**下读取当前用户的**画像标签与偏好标签**——例如投资目标、风险偏好、分析风格和其他个性化兴趣/不感兴趣项

#### b. 知识库

![知识库开关](./images/05-7-%E7%9F%A5%E8%AF%86%E5%BA%93.png)

- 开启「知识库」后，AI 将在必要时搜索所选知识库

#### c. 人机交互 (HITL)

![人机交互开关](./images/05-6-%E4%BA%BA%E6%9C%BA%E4%BA%A4%E4%BA%92.png)

- 允许模型在执行过程中**向用户提问并等待回答**
- 这个功能很强，**建议开启**

#### d. 联网搜索

![联网搜索开关](./images/05-8-%E8%81%94%E7%BD%91%E6%90%9C%E7%B4%A2.png)

- 开启「联网搜索」后，AI 将在必要时使用内置网络搜索工具
- **强烈建议开启**

#### e. 待办事项

- 开启「待办事项」后，AI 将自动识别对话中的任务并**拆解和执行**
- **强烈建议开启**

#### f. 输出内容合法合规检查

- 开启后，系统将在输出时对内容进行**合规校验**
- 如识别到输出内容存在不合法或不符合金融合规要求的情形，系统将**立即停止输出并清空已生成的内容**

### 7. 最大迭代次数
- **范围**: 1-99 次配置
- **用途**: 控制 Agent 的最大执行次数
- **建议值**: 一般建议设置为 **99 次**,给 Agent 足够的循环空间完成复杂任务

### 8. 输出变量
- **text**: agent 生成的内容（text）
- **think**: 模型的思考过程。**部分模型支持 think 输出**，可以使用「思考过程输出」（仅 Chatflow 支持）的节点输出
- **agent 生成的 json**: 结构化输出结果

### 9. 下一步配置
- 支持添加下一个节点

## 运行模式说明

Agent 节点统一采用 **Function Calling 模式**运行，无需选择策略：

- **特点**: 模型通过函数调用使用预定义的工具，在循环中自主规划、调用、判断，直到任务完成
- **优势**: 精确控制，可预测性强，同时具备处理复杂多步任务的能力

## 常见问题

### Q: Agent 节点需要选择运行策略吗？
A: 不需要。Agent 节点没有策略选择，默认均为 Function Calling 模式。

### Q: 如何添加工具？
A: 点击添加工具按钮，从工具列表中选择需要的工具。

### Q: 最大迭代次数如何设置？
A: 范围是 1-99 次，一般建议设置为 99 次，给 Agent 足够的循环空间完成复杂任务。

### Q: Agent 如何选择工具？
A: Agent 会根据任务需求和工具能力自动选择合适的工具。

### Q: 如何优化 Agent 性能？
A: 合理配置工具（工具较多时开启工具搜索）、设置适当的迭代次数。
