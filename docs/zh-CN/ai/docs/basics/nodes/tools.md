## 节点概述

**节点英文名**: Tool(以所选工具的英文名为准)  
**节点中文名称**: 工具 (画布上显示所选工具各自的名称)  
**支持场景**: Chatflow Agent（支持）, Workflow Agent（支持）  

## 功能说明

Tool 节点触发对外部工具（包括长桥内和长桥外）的调用，将调用结果反馈到流程中以供后续节点使用。它提供了强大的工具集成能力，支持各种外部工具和服务的调用。

**添加方式**：点击画布左下角的节点面板，切换到「工具」页签（可在 Infra / OpenAPI 来源间切换），按分类（资讯与社区内容、实时行情、技术分析与选股等）或搜索找到目标工具，点击即可添加到画布：

![工具节点编辑面板：工具说明、输入变量 (含类型/必填/说明，变量引用或直接设值)、展示配置与引用开关、输出变量 text/data、失败时重试、异常处理、下一步节点](./images/14-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. 工具说明
- 面板顶部展示工具名称与功能说明（如「获取新闻详情（批量）：按 ID 批量获取新闻详情」）

### 2. 输入变量
- **参数定义**: 按工具入参逐项展示——参数名、类型（如 array）、是否必填、参数说明（如「要获取详情的 ID 列表，最大长度为 20」）
- **取值方式**: 选择「变量」引用上游变量，或直接设置固定值

### 3. 展示配置与引用
- **展示配置**: 开关，控制工具结果在对话端的展示方式
- **引用**: 开关，控制回答中是否携带该工具结果的引用来源

### 4. 输出变量
- **text** (string): 工具生成的文本内容
- **data** (object): 工具生成的结构内容

### 5. 容错配置
- **失败时重试**: 开关，调用失败时自动重试
- **异常处理**: 下拉选择异常处理策略（默认「无」）

## 工具来源与分类

- **来源**: **Infra 内置工具** / **OpenAPI 自定义工具**（节点面板「工具」页签内切换；第三方 MCP 工具见 Agent 节点与套餐说明）
- **Infra 内置分类**: 资讯与社区内容、实时行情、技术分析与选股、基本面与财务数据、宏观经济数据、AI 分析与信号、数据可视化图表、账户与持仓、订单管理、基础工具与搜索、用户记忆与个性化、帮助文档

## 使用场景

### 1. 行情与资讯
- 获取实时行情、股票相关新闻 / UGC 内容，交给 LLM 总结解读（先查后答，见 2.3 模式 3）

### 2. 技术分析
- 获取 K 线等数据后交给 Code 节点计算指标（大数据量计算不要交给模型，见 2.5 技巧三）

### 3. 账户场景
- 查询账户与持仓、订单信息（面向客户时注意合规边界，不构成投资建议）

### 4. 可视化
- 调用图表类工具，在对话端展示可视化结果

## 配置步骤

1. 在节点面板「工具」页签中按分类或搜索添加工具
2. 配置输入变量（引用上游变量或设置固定值，必填项不可缺）
3. 按需开启展示配置 / 引用、失败时重试与异常处理
4. 试运行验证结果，连接下一个节点

## 常见问题

### Q: 工具执行失败怎么办？
A: 检查必填输入参数是否配置正确，用试运行查看报错；开启失败时重试并配置异常处理策略。

### Q: 为什么找不到某个工具？
A: 可用工具范围随套餐与地区变化（如内置工具 Starter 仅部分可用），详见 Workspace 与套餐体系文档。

### Q: 工具输出怎么在后续节点使用？
A: `text` 适合直接给 LLM / Answer 节点引用；`data` 结构化内容适合给 Code、IF Else 等节点加工判断。

### Q: 工具调用计费吗？
A: 仅特定搜索和爬虫类工具按调用次数计费，其余不计费，详见套餐与用量说明。

## 注意事项

1. **必填参数**: 必填输入变量未配置会导致运行失败
2. **数据真实性**: 提示词中要求 LLM 只基于工具返回的数据作答，不得编造
3. **合规边界**: 面向客户的场景注意输出合规（不构成投资建议）
4. **容错配置**: 重要流程配置失败重试与异常处理
