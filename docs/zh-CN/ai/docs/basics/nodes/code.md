## 节点概述

**节点英文名**: Code  
**节点中文名称**: 代码执行  
**支持场景**: Chatflow Agent（支持）, Workflow Agent（支持）  
**迭代版本**: 版本1  

## 功能说明

Code节点用于运行一段自定义代码（如Python和JavaScript），实现特定业务逻辑或计算，输出结果供后续节点使用。它提供了强大的编程能力，允许用户在工作流中执行自定义的代码逻辑。

## 节点编辑区域

![代码执行节点编辑面板:输入变量(arg1/arg2)、PYTHON3代码编辑器(main函数)、输出变量(result)与失败时重试](./images/11-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. 输入变量配置
- **添加变量**: 点击后新增一行输入变量
- **变量列表**: 支持多行变量的展示，支持删除
- **变量输入**: 支持多个变量的输入
- **变量名**: 支持填写变量名称
- **变量值**: 支持通过【选择变量】组件选择变量值

### 2. 代码输入框
- **语言选择**: 支持Python3和JavaScript两种类型的选择
- **代码编辑**: 提供代码编辑器，支持语法高亮、复制与放大
- **固定入口**: 代码需实现 `main` 函数，返回值为字典，键与输出变量一一对应（如 `def main(arg1: str, arg2: str) -> dict: return {"result": arg1 + arg2}`）

### 3. 输出变量配置
- **变量名称**: 支持填写变量名称
- **变量类型**: 支持选择变量类型
- **添加删除**: 支持添加和删除变量
- **变量类型范围**:
  - String / Array[String]
  - Number / Array[Number]
  - Object / Array[Object]

### 4. 失败时重试
- **开关**: 开启后，代码执行失败时自动重试

### 5. 下一步配置
- 支持添加下一个节点

## 编程语言支持

### 1. Python3
- **版本**: Python 3.x
- **标准库**: 支持Python标准库（第三方库以沙箱实际支持为准）
- **语法**: 完整的Python语法支持

### 2. JavaScript

![JS模式:语言切换为JAVASCRIPT,main函数以解构对象接收输入变量](./images/11-3-JS%E6%A8%A1%E5%BC%8F.png)

- **版本**: Node.js环境
- **标准库**: 支持Node.js标准库
- **语法**: 完整的JavaScript语法支持
- **函数签名**: 与 Python 模式不同,JS 的 `main` 函数以**解构对象**接收输入变量——`function main({arg1, arg2})`,返回对象的字段对应输出变量(如 `return { result: ... }`)

## 常见问题

### Q: 支持哪些编程语言？
A: 目前支持Python3和JavaScript两种编程语言。

### Q: 如何添加输入变量？
A: 点击"+"按钮可以添加新的输入变量行。

### Q: 输出变量类型有哪些？
A: 支持String、Number、Object及其对应的Array类型。

### Q: 代码执行有安全限制吗？
A: 是的，代码执行有安全限制，不能执行危险操作。

### Q: 如何调试代码？
A: 可以使用试运行功能来调试代码，查看执行结果。
