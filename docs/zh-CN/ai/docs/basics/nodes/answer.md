## 节点概述

**节点英文名**: Answer  
**节点中文名称**: 输出答案  
**支持场景**: Chatflow Agent（支持）, Workflow Agent（不支持）  

## 功能说明

Answer 节点用于将节点结果或最终回答输出给 Chat 系统，常用于结束一次对话或向上层调用方提供最终信息。它是 Chatflow Agent 中的终结节点，负责格式化并输出最终的回答内容。

- **图标**: 节点专用图标
- **名称**: 节点名称

- **注释**: 用户添加的说明文字

- **更多按钮**: 点击后展示右键菜单内容

## 节点编辑区域

![Answer 节点编辑面板：回复模版、保存上下文、长期记忆与输出变量](./images/02-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)

### 1. 回复模版编辑

#### a. 编辑框功能
- **支持插入变量**: 可以在模版中插入各种变量
- **支持输入字符**: 支持直接输入文本内容
- **变量选择**: 输入"/"唤起选择变量值的输入框

#### b. 编辑辅助功能
- **长度统计**: 支持统计模版的长度，变量名称计入模版长度统计
- **复制功能**: 点击 copy 按钮复制模版
- **最大化**: 点击最大化按钮，将模版展示最大化

### 2. 保存上下文

**保存上下文功能对于上下文的保存十分重要**,它可以在 Chatflow 运行结束时保存本轮上下文供后续会话使用，这个上下文包括了工具调用的各种信息。

- 在此处选择要保存的上下文变量，如上图中选择了 `LLM/context`(array[context] 类型)
- **如果一个 Chatflow 需要有良好的上下文管理，需要把 LLM 节点或 Agent 节点的上下文 (context) 变量保存在这里**——否则下一轮对话时，模型将无法感知本轮的工具调用过程与中间结果

![Answer 节点编辑面板：回复模版、保存上下文、长期记忆与输出变量](./images/02-2-%E8%8A%82%E7%82%B9%E9%85%8D%E7%BD%AE.png)


### 3. 长期记忆

- 开启后，提取的长期记忆会在内容输出时**同步展示**
- 这不是一个必选的功能，按需开启即可
- 开启后，输出变量区会增加 `user_memory_changes`(array[string] 类型),记录本轮提取到的长期记忆变更

### 4. 附加数据

- 附加数据功能用于主 Agent 的一些功能的实现
- 一般用户自己搭建的 Agent 暂时使用不上，后续功能教学会逐步开放

### 5. 输出变量

- `answer`: String 类型，本节点最终输出的回答内容
- `user_memory_changes`: array[string] 类型，长期记忆变更记录 (仅开启「长期记忆」后出现)

### 6. 下一步配置
- Answer 节点是终止节点，不支持添加下一个节点

## 运行逻辑

Answer 节点的运行逻辑由后端实现，确保答案输出的正确性。

## 右键操作

右键菜单包含以下选项：
1. **更改节点**: 修改节点类型
2. **拷贝**: 复制节点
3. **复制**: 复制节点内容
4. **删除**: 删除节点
5. **帮助链接**: 跳转到帮助文档

## 节点数量控制

- **限制**: 一个 Agent 可以有多个 Answer 节点
- **用途**: 可以作为终结节点使用；多个 Answer 节点适用于不同的分支——例如经过条件判断或问题分类后，各分支走向各自的 Answer 节点，输出对应的回复内容

## 测试运行

- **支持状态**: 不支持测试运行
- **更改节点**: 支持更改节点类型
- **复制功能**: 支持复制、剪贴、删除操作

## 使用场景

### 1. 对话终结
- 在 Chatflow Agent 中作为对话的最终输出
- 将 AI 处理的结果以友好的方式展示给用户

### 2. 结果格式化
- 将复杂的处理结果格式化为用户可读的文本
- 支持变量替换，动态生成个性化内容

### 3. 多语言支持
- 支持不同语言的输出模版
- 可以根据用户语言偏好调整输出格式

## 模版编写技巧

### 1. 直接引用上游节点输出 (最常用)

大多数场景不需要编写复杂模版，**直接选择 LLM 节点或 Agent 节点的输出变量即可**:

- 在回复模版编辑框中输入 `/` 唤起变量选择，选中上游节点的 `text` 输出 (如 `LLM/text`)
- 模版里只放这一个变量，模型生成什么就原样输出什么，简单可靠

### 2. Debug 输出技巧

调试 Chatflow 时，可以**临时在模版中加入中间变量**,把流程内部状态直接打印到回复里观察：

```
【Debug】
分类结果: {{分类节点输出}}
检索命中: {{知识检索输出}}
---
{{LLM/text}}
```

- 能快速定位问题出在哪个环节：分支走错、检索为空还是模型生成异常
- 也可以利用多 Answer 节点的特性，给某个分支单独挂一个 Debug 用的 Answer 节点，输出该分支的中间变量
- **调试完成后记得移除 Debug 内容再发布**,避免内部信息展示给最终用户

## 常见问题

### Q: 如何插入变量？
A: 可以通过输入"/"按钮来插入变量。

### Q: 模版长度如何计算？
A: 模版长度包括所有文本内容和变量名称，变量值不计入长度。

### Q: 支持哪些变量类型？
A: 支持 String、Number、Object、Array 等基本数据类型。

### Q: 如何处理空值？
A: 建议在模版中使用条件判断来处理可能的空值情况。
