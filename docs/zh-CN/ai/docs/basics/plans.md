> 本篇回答三个问题:**我的东西放在哪(Workspace)、我能用什么和能用多少(套餐)、谁来承担用量(Charged By)**。理解这套体系后,平台上所有"为什么这个功能我看不到/用不了/被拦截"的问题都能自己找到答案。

## 一、整体架构:一句话版本

```
Workspace(承载单元) ── 绑定 → 套餐(功能范围 + 用量额度)
```

- **Workspace = 一切发生的地方**:你的 Agent、知识库、用量都以它为边界
- **套餐 = 能用什么 + 能用多少**:决定当前 Workspace 的功能范围和用量额度

下面逐层拆解。

## 二、角色(Role):你是谁

角色描述用户的身份来源与使用场景,平台有两类:

| 角色 | 说明 | 典型用法 |
|------|------|---------|
| **社区用户** | 以个人身份使用平台 | 个人创作、试用、分享 |
| **官方用户** | 平台官方人员 | 提供官方服务、运营与支持 |

注意:角色只区分**身份背景**,不直接决定功能范围和用量上限 —— 那由所在 Workspace 的套餐决定。

## 三、Workspace(工作空间):一切发生的地方

Workspace 是平台中承载使用行为的基本单元:

- 每个用户对应并参与到**一个或多个** Workspace
- 所有 Agent、Workflow、运行行为与**用量消耗**均发生在 Workspace 内
- Workspace 是套餐与用量生效的**边界**

### Workspace 的关键规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | 一对一绑定 | 一个 Workspace 同一时刻只绑定**一个套餐** |
| 2 | 社区 Workspace 自助创建 | 普通用户仅可创建社区 Workspace,注册时自动激活 Starter 套餐 |
| 3 | 官方 Workspace 由平台创建 | 由平台侧创建或授权,普通用户不可自行创建 |
| 4 | 能力随 Workspace 切换 | 同一个人在不同 Workspace 中看到的功能入口自动变化 |
| 5 | 只展示可用的功能 | 用户只感知"当前 Workspace 能做什么",不可用的功能直接隐藏入口,无需理解背后的套餐细节 |
| 6 | 有且仅有一个 Owner | 每个 Workspace 只能有**一个 Owner**;Editor 和 Viewer 的数量取决于**套餐上的成员数量限制** |

### Workspace 成员角色

| 成员角色 | 数量 | 权限 |
|---------|------|------|
| **Owner** | 每个 Workspace **仅一个** | 全部权限,且**唯一**能执行订阅购买/升级/降级/退订等商业操作(见 4.3) |
| **Editor** | 随套餐限制 | 创建、编辑 Workspace 内的 Agent、知识库等资源 |
| **Viewer** | 随套餐限制 | 查看和使用 Workspace 内的资源,不可编辑 |

注意区分:第二节的角色(社区/官方用户)描述的是**平台身份**,这里的 Owner/Editor/Viewer 是**同一 Workspace 内部**的成员权限,二者相互独立。

## 四、套餐(Plan):能用什么、能用多少

套餐是平台中可被购买或发放的**商业对象**,决定当前 Workspace 的功能范围与用量额度。

### 4.1 三个套餐

| 套餐 | 类型 | 定位 | 价格(USD 基准)* | 获得方式 |
|------|------|------|--------------|---------|
| **Starter** | 免费 | 个人入门 | $0 | 注册自动激活 |
| **Pro** | 付费 | 个人专业版 | ~$20/月 | 连续包月订阅 |
| **Premium** | 付费 | 高级版 | ~$100/月 | 连续包月订阅 |

> \* 价格可能会**动态调整**,以实际收费为准。

### 4.2 套餐权益差异速查

| 权益 | Starter | Pro | Premium |
|------|---------|-----|---------|
| 月度用量额度 | 基础额度 | 更高额度 | 最高额度(具体以套餐页实时展示为准) |
| Agent 创建(Agentic Chat / Chatflow) | ✓ | ✓ | ✓ |
| 内置工具 | 部分 | 全量 | 全量 |
| 第三方 MCP Server | ✗ | ✗ | ✓ |
| OpenAPI 工具(自行配置) | ✓ | ✓ | ✓ |
| 自定义 Skill 数量 | 3 | 20 | 100 |
| 官方内置 Skill(财报分析等) | ✗ | ✓ | ✓ |
| 知识库容量 | 50MB | 5GB | 20GB |
| 发布 Agent 到广场 | ✗ | ✓(需安全扫描) | ✓(需安全扫描) |
| 使用/Fork 广场 Agent | ✓ | ✓ | ✓ |

> **⚠️ 套餐权益以实际权益为准**:本帮助文档的更新可能滞后,本节的定价与权益内容可能与实际权益存在**较大差异**,一切以产品内套餐页实时展示为准。运营侧调整套餐配置时,存量用户当前计费周期内不受变更影响。

### 4.3 订阅规则要点

- **统一连续包月**,不提供单月购买(与主流 AI 产品一致)
- 支付渠道:iOS 走 Apple IAP,Android/Web 走 Stripe;同一 Workspace 同一时刻只能有一个活跃订阅渠道
- **仅 Workspace Owner** 可执行购买 / 升级 / 降级 / 退订操作
- **升级**:立即生效,按渠道规则补差价
- **降级**:次月生效,生效前可撤回;当前用量周期保持原额度,下周期按新套餐
- **退订**:到期前可恢复自动续费;到期后回落到 Starter
- 币种在首次购买时锁定,各地区定价见 [1.6 分地区服务说明](regions)

## 五、用量(Usage):怎么计、怎么扣

> **用量在长桥 AI 产品间通用**:同一用户的额度**同时适用于官方 Chatbot(LongbridgeAI 对话端)和 Agent Platform** —— 在 Chatbot 里问答与在平台上运行 Agent,消耗的是同一份额度。

### 5.1 什么行为消耗用量

系统对 5 种计费单元实时采集,统一换算为 USD:

| 计费单元 | 计量方式 |
|---------|---------|
| LLM 调用 | 按模型返回的 input/output token 数 |
| Embedding(知识库向量化) | 按处理的 token 数 |
| Rerank | 按处理的 token 数 |
| 沙箱运行(Code 节点等) | 按运行时长,向上取整到分钟 |
| 搜索/爬虫工具 | 按调用次数(仅特定搜索和爬虫工具计费,OpenAPI 等不计费) |

### 5.2 额度的发放节奏:月度总额 + 周滚动释放

- **月度总额度**:每个计费周期(月)分配总额度;周期结束时归零,新周期重新分配,**不结转**
- **周滚动释放**:月度额度按每 7 天滚动释放,每周可用 ≈ 月度总额 ÷ 4;当周用完需等下一个滚动周,当周没用完也**不顺延**
- 用量周期独立滚动,与订阅周期(续费日)无关
- 套餐额度之外,还可能持有**权益卡**(限时按更高档位提升功能权益并叠加用量,不改变订阅关系),见 [1.8 HKSG 权益卡](hksg-benefits)

> 设计意图:防止一天烧光整月额度,让消耗节奏可控。

### 5.3 超额了会怎样

超额后会被拦截;是否提供用量提前预警(如 80%/90% 提示)**以实际线上情况为准**:

| 场景 | 拦截行为 |
|------|---------|
| 对话/Workflow/试运行等运行类 | 运行前检查剩余额度,不足则阻止本次运行并提示升级套餐 |
| 知识库容量超限 | 禁止新增文件;超限文件**按上传时间从最旧开始**标记为**禁用**(不参与检索),不自动删除,删文件或升级可恢复 |
| Skill 数量超限 | 阻止创建新 Skill,提示删除已有或升级;权益卡到期回落导致的超限,已有内容保留、仅不能新增(见 [1.8](hksg-benefits)) |

### 5.4 谁来承担用量(Charged By)

一次运行消耗的用量记在谁头上,取决于 Agent 归属和你与该 Workspace 的成员关系:

```
用户 A(归属 Workspace A)使用某个 Agent 时:
├─ Agent 属于 Workspace A(自己的)      → Workspace A 承担
├─ Agent 属于 Workspace B,A 是 B 的成员 → Workspace B 承担(开发者付费)
├─ Agent 属于 Workspace B,A 不是成员    → Workspace A 承担(使用者付费)
└─ 系统行为(AI 辅助创建、合规校验等)     → 平台承担,不扣任何用户额度
```

几个具体场景:

| 场景 | 承担方 |
|------|--------|
| 正式对话运行 | 按上面的归属规则 |
| Agent 整体试运行 / 节点试运行 | 开发者(自己调试自己付) |
| 上下文压缩、长期记忆读写 | 与对话运行一致 |
| AI 辅助创建 Agent、合规校验 | 平台 |

### 5.5 配置时 vs 运行时:一个容易混淆的点

**使用者的套餐只影响用量额度,不影响 Agent 已具备的功能。**

| 阶段 | 判定依据 | 决定什么 |
|------|---------|---------|
| **配置时**(开发者搭 Agent) | Agent 所属 Workspace 的套餐 | 开发者能在编辑器里选到哪些工具、Skill、MCP |
| **运行时**(使用者用 Agent) | Agent 已配置的功能 + 内容层鉴权 | 使用者直接可用,功能继承自 Agent 所属 Workspace,不受自己套餐限制 |

例:Premium 开发者在 Agent 里配置了第三方 MCP 工具,Starter 用户使用这个 Agent 时**照样能用**该工具 —— 只是消耗的是自己 Workspace 的用量额度(若按使用者付费)。

## 六、模型分级与用量的关系

- 模型分为「**主流**」和「**SOTA**」两级;SOTA 模型有明确标识,单位消耗更高
- Chatflow/Workflow 支持**节点级模型配置**:简单任务(分类、格式化)用主流模型,核心推理用 SOTA,是控制用量最有效的手段
- 部分模型因厂商条款限制仅平台官方可用,普通套餐的模型选择器中不会展示

## 七、常见问题

| 问题 | 答案 |
|------|------|
| 为什么我在编辑器里看不到某个工具? | 当前 Workspace 的套餐不含该工具(如第三方 MCP 需 Premium) |
| 为什么同事能用的功能我没有? | 你们所在的 Workspace 不同,能力随 Workspace 变化 |
| 额度还有但运行被拦截? | 可能是当前 7 天滚动周的额度用完了,月度余额要等下个滚动周释放 |
| 用别人广场上的 Agent 扣谁的量? | 你不是对方 Workspace 成员时,扣你自己的(使用者付费) |
| 试运行收费吗? | 收,消耗开发者自己 Workspace 的额度;但 AI 辅助创建、合规校验由平台承担 |
| 想要更高额度/更多功能? | Workspace Owner 在套餐页升级,立即生效 |
