> 本篇带你认识平台的 8 个主要页面：每个页面是干什么的、入口在哪、常用操作有哪些。配合截图快速建立对平台的整体印象，细节规则见各页面对应的专题文档。

## Agent 列表

![Agent 列表](./images/1.2-1-Agent%E5%88%97%E8%A1%A8.png)

当前 Workspace 内所有 Agent 的管理入口：

- 查看你有权访问的全部 Agent 及其状态 (草稿 / 已发布)
- 搜索、筛选定位目标 Agent
- 新建 Agent、进入编辑、复制、删除等管理操作
- 注意:Agent 与列表内容以 **Workspace 为边界**,切换 Workspace 后列表随之变化 (见 [1.5](plans))

## 创建 Agent

![创建 Agent](./images/1.2-2-%E5%88%9B%E5%BB%BAAgent.png)

创建入口支持两种模式，按需选择：

| 模式 | 搭建方式 | 适合 |
|------|---------|------|
| **Agentic Chat** | 配置式：提示词 + 挂工具 | 快速验证想法、轻量场景 |
| **Chatflow** | 画布编排：节点 + 连线 | 多分支路由、精确控制的生产级场景 |

- 支持 **AI 辅助创建**:描述需求，由 AI 生成初始配置 (此部分消耗由平台承担)
- 上手教程见 [1.3 快速上手](quick-start),模式选择技巧见 [2.5 技巧一](../tutorials/mode-model-selection)

## 知识库管理

![知识库管理](./images/1.2-3-%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86.png)

管理供 Agent 检索引用的知识文件：

- 上传、查看、删除知识文件，查看向量化处理状态
- 容量额度随套餐变化 (如 Starter 50MB / Pro 5GB / Premium 20GB，以套餐页实时展示为准)
- 容量超限时禁止新增，超限文件**按上传时间从最旧开始**标记为**禁用**(不参与检索),不自动删除
- 知识库能力详解见 [1.7 平台能力 · 知识库](capabilities/knowledge-base)

## Skill 管理

![Skill 管理](./images/1.2-4-Skill%E7%AE%A1%E7%90%86.png)

管理 Agent 可挂载的 Skill:

- 创建、编辑、删除**自定义 Skill**(数量上限随套餐)
- 查看可用的**官方内置 Skill**(财报分析等，需 Pro 及以上套餐)
- Skill 数量超限时无法创建，需删除已有或升级套餐
- Skill 体系详解见 [1.7 平台能力 · Skill 体系](capabilities/skill)

## 空间用户管理

![空间用户管理](./images/1.2-5-%E7%A9%BA%E9%97%B4%E7%94%A8%E6%88%B7%E7%AE%A1%E7%90%86.png)

管理当前 Workspace 的成员与权限：

- 查看成员列表及各自的成员角色
- 成员角色分三种：**Owner**(每个 Workspace 仅一个，拥有全部权限)、**Editor**(可编辑资源)、**Viewer**(只读使用);Editor 与 Viewer 的数量取决于套餐上的成员数量限制
- 仅 Owner 可执行订阅购买/升级等商业操作
- 成员角色规则详见 [1.5 · Workspace 成员角色](plans)

## 用量 (Usage)

> 💡 **入口说明**:用量、套餐、订单三个页面共用一个入口——点击左下角**个人头像**打开菜单，选择「**工作区套餐**」,在展开的二级菜单中分别进入「用量」「套餐」「订单」:

![用量/套餐/订单入口：个人头像菜单 → 工作区套餐](./images/1.2-9-%E7%94%A8%E9%87%8F%E5%A5%97%E9%A4%90%E8%AE%A2%E5%8D%95%E5%85%A5%E5%8F%A3.png)

![用量页](./images/1.2-6-%E7%94%A8%E9%87%8F.png)

查看额度余额与消耗明细：

- 有生效中的权益卡时，顶部展示**权益卡状态卡片**(体验档位 + 剩余天数 + 叠加后的当周可用额度)
- 展示当前 7 天滚动周的可用额度与月度余额
- 消费明细展示每笔消耗的来源，以及由哪个服务主体收取 (charged by)
- 计费单元与扣量规则见 [1.5 · 用量](plans)

## 套餐 (Plan)

> 入口：个人头像菜单 → 工作区套餐 → 套餐 (见[第六节入口说明](#六用量usage))

![套餐页](./images/1.2-7-%E5%A5%97%E9%A4%90.png)

查看与管理当前 Workspace 的套餐：

- 展示当前套餐、各档位权益对比与价格 (**以本页实时展示为准**,帮助文档可能滞后)
- 购买 / 升级 / 降级 / 退订入口 (**仅 Workspace Owner 可操作**)
- 升级立即生效补差价;降级次月生效;退订到期后回落 Starter
- 定价币种按注册地区固定，SG 用户页面价格不含税 (GST 由支付渠道额外收取),见 [1.6](regions)

## 订单页面

> 入口：个人头像菜单 → 工作区套餐 → 订单 (见[第六节入口说明](#六用量usage))

![订单页](./images/1.2-8-%E8%AE%A2%E5%8D%95.png)

查看订阅相关的交易记录：

- 订单列表：每笔订阅/续费的时间、金额、币种与状态
- 支付渠道信息 (Apple IAP / Stripe)
- 订单归属的服务主体与你的注册地区一致
