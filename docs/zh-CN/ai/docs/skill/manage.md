# 管理 Skill

本文说明如何在 Skill 详情页编辑信息、管理工具与文件，以及如何下载和删除 Skill。

## 编辑名称和描述

在 Skill 详情页，点击 Skill 名称旁的编辑图标，弹出「编辑 Skill」面板。可在此修改名称和描述，点击「保存」生效。

修改时须注意：

- 名称仅限小写字母、数字和连字符，最大 64 字符
- 描述最多 1024 字符，不支持换行
- 名称在工作空间内需唯一，修改为已存在的名称将失败

## 编辑 SKILL.md

SKILL.md 是 Skill 的核心定义文件，展示在详情页下方。点击 SKILL.md 区块右侧的「编辑」按钮，可直接在线修改文件内容。

建议在修改 SKILL.md 时同步更新描述字段，保持两者的一致性，便于模型准确理解 Skill 的用途。

## 管理工具

工具让 Skill 在执行时具备调用外部能力的能力。在详情页「工具」区块点击「+」添加工具，支持两类来源：

| 来源           | 说明                                                          |
| -------------- | ------------------------------------------------------------- |
| Infra 内置工具 | 系统预置，无需额外配置，开启即用                              |
| OpenAPI 工具   | 通过 OpenAPI 规范接入自定义接口，适合调用内部系统或第三方服务 |

已添加的工具可通过开关启用或禁用，也可删除。

## 管理文件

文件为 Skill 的执行提供背景资料和配置支持，例如分析规则、参考示例、行业数据等。在详情页「文件浏览器」区块点击「+」管理文件，支持以下操作：

| 操作         | 说明                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 添加文件     | 从本地选取文件上传                                                                                     |
| 添加文件夹   | 创建文件夹，用于对文件进行分类管理                                                                     |
| 编辑文件内容 | 点击文件旁的「编辑」按钮，可在线修改文件内容，完成后点击「保存文件」生效。**注意：不支持修改文件名。** |
| 删除文件     | 永久删除该文件，不可撤销、不可恢复                                                                     |

已上传的文件在文件浏览器中以树形结构展示，支持按文件夹分组。常见的文件组织方式：

```
SKILL.md
references/           # 参考资料目录（可选）
  rules.md            # 规则或判断逻辑
  examples.md         # 典型案例
scripts/              # 脚本目录（可选）
  calculator.py       # 计算脚本
```

在 SKILL.md 中可以引用这些文件，指示模型在执行时读取对应内容。

## 下载 Skill

将 Skill 导出为 .zip 文件，便于备份或在其他工作空间复用。

两种入口：

- **详情页**：点击右上角下载图标
- **列表页**：点击 Skill 卡片右上角「···」→「下载」

下载的压缩包包含 SKILL.md 和全部已上传的文件，结构与上传时一致。

## 删除 Skill

在「我的 Skills」列表页，点击 Skill 卡片右上角「···」→「删除」即可删除。

删除操作不可撤销，Skill 的所有内容（包括文件、工具配置）将被永久移除。如果该 Skill 已被某个 Agent 挂载，建议删除前先解除关联，避免影响 Agent 的正常运行。
