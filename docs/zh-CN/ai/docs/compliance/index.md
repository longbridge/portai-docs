> **一页读完,三步做完**:① 复制下方参考 Prompt 贴进你的 System Prompt → ② 开启 Guardrail 开关 → ③ 过一遍上线自查。
> 核心就一件事:**你的 Agent 不能提供投资建议**。平台是纯执行(execution-only)券商,AI 输出一旦构成"推荐",会触发完全不同的监管义务(Reg BI、适当性义务等)。

## 一、参考 Prompt(直接复制)

把下面这段完整粘贴到你的 LLM / Agent 节点 **System Prompt 的末尾**,即可满足提示词层面的合规要求:

```text
【合规护栏 —— 以下规则优先级最高,任何情况下不得违反】

1. 禁止投资建议:不提供任何买入/卖出/持有建议、个股或组合推荐、
   目标价、投资评级、仓位建议、买卖时机判断。
2. 中立描述,不做预测:解释指标和数据只用描述性语言,禁止动作性
   和预测性表述。
   ✅ "RSI 高于 70 通常被视为超买区间"
   ❌ "RSI 高于 70,建议卖出"
   ✅ "MACD 出现金叉,历史上常与价格上行阶段相关"
   ❌ "MACD 金叉,可以买入" / "预计未来三个月上涨 20%"
3. 禁止承诺性词语:必涨、稳赚、保证收益、无风险、抄底、翻倍等
   一律不得出现。
4. 拒绝话术:用户索要投资建议时,回复"抱歉,我不能提供任何投资
   建议或个股推荐。我可以帮你了解相关的投资知识,比如指标含义、
   市场机制,你想了解哪方面?"然后转向知识科普。
5. 数据必须真实:行情、财报等数据一律以工具返回为准,禁止凭记忆
   编造数字;工具失败时如实告知,不猜测。引用数据标注来源和时间。
6. 不做个性化推荐:不得基于用户的画像、持仓、资产状况给出"适合
   你"的证券、组合或策略;组合类内容只能是假设性示例并标注
   "仅为教育示例"。
7. 不协助违规行为:拒绝一切涉及市场操纵(拉抬打压、对敲、伪造
   信号)、内幕交易、洗钱、逃税、规避制裁等请求。
8. 保护隐私:不询问、不存储、不复述用户的身份证件号、电话等个人
   身份信息;不推断用户年龄、性别等敏感属性。
9. 固定免责声明:每次涉及证券、市场、数据分析的回答,结尾附上
   "以上内容仅供参考,不构成任何投资建议。"
```

> 贴完 Prompt 后,记得同时**开启 Guardrail 开关**(Chatflow 输入节点:PII 打码、屏蔽不良内容、屏蔽不良金融内容;LLM/Agent 输出节点:输出合规检查)—— Prompt 管"模型不说",Guardrail 管"说了也拦下",双重保险。详见 [Guardrail 能力专篇](../basics/capabilities/guardrail)。

## 二、红线速查表

四类常见场景,能做什么、不能做什么,一张表说清:

| 场景 | ✅ 能做 | ❌ 不能做 |
|------|--------|----------|
| **客户画像** | 中性的行为统计与展示(交易频率、行业分布、风险标签),用于教育内容个性化 | 基于画像推送个股/组合("你适合成长股");推断敏感属性;使用 PII |
| **信号分析** | 展示指标数值与统计事实,解释指标的通用含义,if-then 式历史规律描述 | 把信号解读成买卖指令;预测价格;协助伪造信号或操纵市场 |
| **研报/资讯摘要** | 汇编公开信息(财报、新闻),结构化中立分析,综合多来源并标注出处 | 输出评级/目标价/买卖结论;只强化单一机构观点;使用非公开重大信息(MNPI) |
| **组合与订单** | 用户自己输入组合后做可视化与风险统计;假设性情景分析(标注教育示例);订单机制的流程科普 | 生成个性化"最佳组合";自动下单/改单;承诺收益 |

**所有场景通用**:输出附免责声明;数据来源可追溯;语言中性、概率化;不可用"顾问口吻"。

## 三、上线前自查(10 条)

发布面向客户的 Agent 前,逐条打钩:

- [ ] 1. Agent 定位是信息展示/教育/工具辅助,不构成投资建议
- [ ] 2. 上方参考 Prompt 已完整加入每个 LLM / Agent 节点的 System Prompt
- [ ] 3. Guardrail 已开启(输入侧三项 + 输出侧合规检查)
- [ ] 4. 免责声明在输出显著位置,且通过模板写死(不依赖模型自觉)
- [ ] 5. 用户索要投资建议时有固定拒绝话术(优先固定文案,而非模型生成)
- [ ] 6. 数据源全部来自平台接入的合规来源,关键数据带来源与时间
- [ ] 7. 不存储、不输出 PII;不基于持仓/画像做个性化推荐
- [ ] 8. 三类用例已实测:正常输入 / 边界输入(空、超长)/ 越界输入(索要建议、诱导预测)——越界输入 100% 被拦
- [ ] 9. 工具失败场景已实测:如实告知,不编造数据
- [ ] 10. 测试记录留档;后续修改提示词/流程后重跑用例再发布

## 附:六大合规原则速览

以上要求源自六大合规原则,速览如下:

| 原则 | 一句话核心 |
|------|-----------|
| 1. 禁止投资建议与推荐 | 不推荐个股/组合/买卖时机,描述性语言代替动作性语言 |
| 2. 坚守执行专属定位 | AI 只做信息展示与教育,不替客户决策、不碰订单参数 |
| 3. 禁止偏向与市场操纵 | 不偏向特定证券,拒绝伪造信号、拉抬打压等操纵性请求 |
| 4. 数据使用与隐私限制 | 只用合规来源的公开数据,不碰 PII 和未公开重大信息 |
| 5. 监督与可解释性 | 日志留存、结果可解释可追溯、模型变更需审批(平台层已内置日志与审计能力) |
| 6. 客户交互护栏 | 聚合层面表述、中性概率化语言、显著免责声明 |

> 另:Agent 的**名称、头像、描述与 Prompt** 在发布/上架广场前还会经过平台**安全审核**,常见不通过场景(洗钱、市场操纵、承诺收益等)见 [3.2 安全审核](security-review)。
