■ 截图本地化管理

筛选：
用途：以简体中文截图为基准，检查繁体（zh-HK）和英文（en）版本的截图是否已本地化，并支持直接替换。

使用步骤：
1. 用 Chrome / Edge 打开本页面（依赖 File System Access API，Safari / Firefox 不支持写入）；
2. 点击「选择仓库 docs 目录」，选中 portai-docs/docs 目录并授权读写；
3. 工具会扫描 zh-CN/ai/docs 下的全部截图，与 zh-HK / en 同路径文件逐字节比对：
   待本地化 与简中文件内容相同（还是简中截图的拷贝）  已本地化 内容不同（已替换为对应语言截图）  缺失 文件不存在；
4. 把新截图拖拽到对应语言的卡片上，或点击「替换…」选择文件，即可直接写入仓库对应路径。简体中文基准截图同样支持替换（会二次确认）——基准更新后，繁/英状态将按新基准重新判定，旧截图未同步更新时会显示为"已本地化"，注意甄别。

提示：替换后记得在本地预览（bun run dev）确认效果，再 git 提交。
