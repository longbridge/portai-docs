# tools

存放编辑、维护文档用的小工具（区别于 `scripts/`——那里是构建流水线脚本）。

## screenshot-manager.html — 截图本地化管理

以简体中文（zh-CN）截图为基准，管理繁体（zh-HK）和英文（en）版本的截图本地化。

**用法**：用 Chrome / Edge 直接打开 `tools/screenshot-manager.html`（无需启动任何服务），点击「选择仓库 docs 目录」并授权读写，选中本仓库的 `docs/` 目录（选仓库根目录也可以，会自动识别）。

**功能**：

- 扫描 `docs/zh-CN/ai/docs` 下全部截图，与 zh-HK / en 同路径文件逐字节（SHA-256）比对：
  - **待本地化**：目标语言文件与简中文件内容相同，说明还是简中截图的拷贝；
  - **已本地化**：内容不同，已替换为对应语言的截图；
  - **缺失**：目标路径没有该文件。
- 每张截图显示被哪些 zh-CN 文档引用，未被引用的会标出（可能已废弃）。
- 把新截图**拖拽到对应语言的卡片上**（或点「替换…」选文件），直接写入仓库对应路径，无需手动找目录。
- 「复制待办清单」可导出 Markdown 格式的待本地化清单。

**注意**：`scripts/mirror-locales.ts` 从 zh-CN 镜像生成 zh-HK / en 时，图片只在目标缺失时才拷贝，不会覆盖已本地化的截图（翻译完成的 en 文档同理受保护）。
